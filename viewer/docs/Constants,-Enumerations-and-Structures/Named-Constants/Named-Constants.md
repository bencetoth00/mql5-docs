# Named Constants


All constants used in MQL5 can be divided into the following groups:

- [Predefined macro substitutions](Predefined-Macro-Substitutions/Predefined-Macro-Substitutions.md) – values are substituted during compilation;
- [Mathematical constants](Mathematical-Constants/Mathematical-Constants.md) – values of some mathematical expressions;
- [Numerical type constants](Numerical-Type-Constants/Numerical-Type-Constants.md) –  some of the simple type restrictions;
- [Uninitialization reason codes](Uninitialization-Reason-Codes/Uninitialization-Reason-Codes.md) – description of uninitialization reasons;
- [Checking Object Pointer](Checking-Object-Pointer/Checking-Object-Pointer.md) – enumeration of types of pointers returned by the [CheckPointer()](../../Common-Functions/CheckPointer/CheckPointer.md) function;
- [Other constants](Other-Constants/Other-Constants.md) – all other constants.
