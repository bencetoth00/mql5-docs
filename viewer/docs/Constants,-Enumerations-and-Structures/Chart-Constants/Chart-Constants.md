# Chart Constants


Constants describing various properties of charts are divided into the following groups:

- [Types of events](Types-of-Chart-Events/Types-of-Chart-Events.md) – events that occur when working with charts;
- [Chart timeframes](Chart-Timeframes/Chart-Timeframes.md) – standard built-in periods;
- [Properties of chart](Chart-Properties/Chart-Properties.md) – identifiers that are used as parameters of [chart functions](../../Chart-Operations/Chart-Operations.md);
- [Positioning constants](Positioning-Constants/Positioning-Constants.md) - value of a parameter of the [ChartNavigate()](../../Chart-Operations/ChartNavigate/ChartNavigate.md) function;
- [Displaying charts](Chart-Representation/Chart-Representation.md) - setting the chart appearance.
