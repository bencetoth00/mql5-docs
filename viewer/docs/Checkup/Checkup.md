# State Checking

Functions that return parameters of the current state of the client terminal

| Function | Action |
| --- | --- |
| [GetLastError](GetLastError/GetLastError.md) | Returns the last error |
| [IsStopped](IsStopped/IsStopped.md) | Returns true, if an mql5 program has been commanded to stop its operation |
| [UninitializeReason](UninitializeReason/UninitializeReason.md) | Returns the code of the reason for deinitialization |
| [TerminalInfoInteger](TerminalInfoInteger/TerminalInfoInteger.md) | Returns an integer value of a corresponding property of the mql5 program environment |
| [TerminalInfoDouble](TerminalInfoDouble/TerminalInfoDouble.md) | Returns a double value of a corresponding property of the mql5 program environment |
| [TerminalInfoString](TerminalInfoString/TerminalInfoString.md) | Returns a string value of a corresponding property of the mql5 program environment |
| [MQLInfoInteger](MQLInfoInteger/MQLInfoInteger.md) | Returns an integer value of a corresponding property of a running mql5 program |
| [MQLInfoString](MQLInfoString/MQLInfoString.md) | Returns a string value of a corresponding property of a running mql5 program |
| [Symbol](Symbol/Symbol.md) | Returns the name of a symbol of the current chart |
| [Period](Period/Period.md) | Returns the current chart timeframe |
| [Digits](Digits/Digits.md) | Returns the number of decimal digits determining the accuracy of the price value of the current chart symbol |
| [Point](Point/Point.md) | Returns the point size of the current symbol in the quote currency |
