# Working with Events

# Event Functions

This group contains functions for working with custom events and timer events. Besides this group, there are special functions for handling [predefined events](../Language-Basics/Functions/Event-Handling-Functions/Event-Handling-Functions.md).

| Function | Action |
| --- | --- |
| [EventSetMillisecondTimer](EventSetMillisecondTimer/EventSetMillisecondTimer.md) | Launches event generator of the high-resolution timer with a period less than 1 second for the current chart |
| [EventSetTimer](EventSetTimer/EventSetTimer.md) | Starts the timer event generator with the specified periodicity for the current chart |
| [EventKillTimer](EventKillTimer/EventKillTimer.md) | Stops the generation of events by the timer in the current chart |
| [EventChartCustom](EventChartCustom/EventChartCustom.md) | Generates a custom event for the specified chart |
