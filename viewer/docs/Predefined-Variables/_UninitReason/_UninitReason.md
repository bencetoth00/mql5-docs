# _UninitReason

int \_UninitReason

The \_UninitReason variable contains the code of the program [uninitialization reason](../../Constants,-Enumerations-and-Structures/Named-Constants/Uninitialization-Reason-Codes/Uninitialization-Reason-Codes.md).

Usually, this code is obtained by [UninitializeReason()](../../Checkup/UninitializeReason/UninitializeReason.md)the function.
