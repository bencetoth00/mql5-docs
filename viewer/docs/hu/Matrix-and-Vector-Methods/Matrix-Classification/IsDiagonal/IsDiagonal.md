# IsDiagonal


Ellenőrzi, hogy egy négyzetes mátrix átlómátrix-e.

```cpp
bool matrix::IsDiagonal();
```

Visszatérési érték

True értéket ad vissza, ha a négyzetes mátrix átlómátrix.

Megjegyzés

Az átlómátrix főátlója alatt és felett minden elem 0.

Az n×n méretű nullmátrix átlómátrix.

Átlómátrix

```cpp
   v  0  0  0  0  0
   0  v  0  0  0  0
   0  0  v  0  0  0
   0  0  0  v  0  0
   0  0  0  0  v  0
   0  0  0  0  0  v
```
