# Min

# Min (Get metódus)

Lekéri a fuzzy változó minimális értékét.

```cpp
double  Min()
```

Visszatérési érték

A fuzzy változó minimális értéke.

# Min (Set metódus)

Beállítja a fuzzy változó minimális értékét.

```cpp
void  Min(
   const double  min      // minimum value for a fuzzy variable
   )
```

Paraméterek

min

[in]  A fuzzy változó minimális értéke.
