# Terms

# Terms (lekérő metódus)

Lekéri az adott fuzzy változó fuzzy kifejezéseinek listáját.

```cpp
CList*  Terms()
```

Visszatérési érték

Az adott fuzzy változó fuzzy kifejezéseinek listája.

# Terms (beállító metódus)

Beállítja az adott fuzzy változó fuzzy kifejezéseinek listáját.

```cpp
void  Terms(
   CList*&  terms      // list of fuzzy terms for the given variable
   )
```

Paraméterek

terms

[in]  Az adott fuzzy változó fuzzy kifejezéseinek listája.
