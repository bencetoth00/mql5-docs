# Max

# Max (Get metódus)

Lekéri a fuzzy változó maximális értékét.

```cpp
double  Max()
```

Visszatérési érték

A fuzzy változó maximális értéke.

# Max (Set metódus)

Beállítja a fuzzy változó maximális értékét.

```cpp
void  Max(
   const double  max      // maximum value for a fuzzy variable
   )
```

Paraméterek

max

[in]  A fuzzy változó maximális értéke.
