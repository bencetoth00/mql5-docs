# CompositionType


Beállítja az összetételi operátort.

```cpp
void  CompositionType(
   MfCompositionType  value      // operator type
   )
```

Paraméterek

value

[in]  Az összetételi operátor típusa.

Megjegyzés

A következő operátortípusok érhetők el:

- MinMF (a függvények minimuma)
- MaxMF (a függvények maximuma)
- ProdMF (a függvények szorzata)
- SumMF (a függvények összege)
