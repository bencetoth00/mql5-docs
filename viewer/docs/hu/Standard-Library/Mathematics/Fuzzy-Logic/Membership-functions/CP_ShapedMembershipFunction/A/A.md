# A (Get metódus)

Lekéri a fuzzy halmaz kezdetének paraméterét.

```cpp
double  A()
```

Visszatérési érték

A fuzzy halmaz kezdetének paramétere.

# A (Set metódus)

Beállítja a fuzzy halmaz kezdetének paraméterét.

```cpp
void  A(
   const double  a      // parameter of the fuzzy set beginning
   )
```

Paraméterek

a

[in] A fuzzy halmaz kezdetének paramétere.
