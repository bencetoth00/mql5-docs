# D

# D (Get metódus)

Lekéri a fuzzy halmaz végének paraméterét.

```cpp
double  D()
```

Visszatérési érték

A fuzzy halmaz vége paraméterének értéke.

# D (Set metódus)

Beállítja a fuzzy halmaz végének paraméterét.

```cpp
void  D(
   const double  d      // value of the fuzzy set end parameter
   )
```

Paraméterek

d

[in]  A fuzzy halmaz vége paraméterének értéke.
