# A

# A (Get metódus)

Lekéri a növekvő intervallum kezdetének paraméterét.

```cpp
double  A()
```

Visszatérési érték

A növekvő intervallum kezdetének paramétere.

# A (Set metódus)

Beállítja a növekvő intervallum kezdetének paraméterét.

```cpp
void  A(
   const double  a      // increasing interval start parameter
   )
```

Paraméterek

a

[in] A növekvő intervallum kezdetének paramétere.
