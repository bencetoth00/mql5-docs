# B (Get metódus)

Lekéri a fuzzy halmaz magjának első paraméterét.

```cpp
double  B()
```

Visszatérési érték

A fuzzy halmaz magjának első paramétere.

# B (Set metódus)

Beállítja a fuzzy halmaz magjának első paraméterét.

```cpp
void  B(
   const double  b      // the first parameter of the fuzzy set core
   )
```

Paraméterek

b

[in]  A fuzzy halmaz magjának első paramétere.
