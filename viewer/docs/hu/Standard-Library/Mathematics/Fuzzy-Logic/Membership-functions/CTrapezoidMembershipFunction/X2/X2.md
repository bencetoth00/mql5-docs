# X2 (lekérő metódus)

Lekéri az X tengelyen lévő második pont értékét.

```cpp
double  X2()
```

Visszatérési érték

Az X tengelyen lévő második pont értéke.

# X2 (beállító metódus)

Beállítja az X tengelyen lévő második pont értékét.

```cpp
void  X2(
   const double  x2      // value of the second point on the X axis
   )
```

Paraméterek

x2

[in]  Az X tengelyen lévő második pont értéke.
