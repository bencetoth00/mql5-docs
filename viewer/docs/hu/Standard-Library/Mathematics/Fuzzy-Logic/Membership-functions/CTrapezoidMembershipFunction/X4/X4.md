# X4 (lekérő metódus)

Lekéri az X tengelyen lévő negyedik pont értékét.

```cpp
double  X4()
```

Visszatérési érték

Az X tengelyen lévő negyedik pont értéke.

# X4 (beállító metódus)

Beállítja az X tengelyen lévő negyedik pont értékét.

```cpp
void  X4(
   const double  x4      // value of the fourth point on the X axis
   )
```

Paraméterek

x4

[in]  Az X tengelyen lévő negyedik pont értéke.
