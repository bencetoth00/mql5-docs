# X3 (lekérő metódus)

Lekéri az X tengelyen lévő harmadik pont értékét.

```cpp
double  X3()
```

Visszatérési érték

Az X tengelyen lévő harmadik pont értéke.

# X3 (beállító metódus)

Beállítja az X tengelyen lévő harmadik pont értékét.

```cpp
void  X3(
   const double  x3      // value of the third point on the X axis
   )
```

Paraméterek

x3

[in]  Az X tengelyen lévő harmadik pont értéke.
