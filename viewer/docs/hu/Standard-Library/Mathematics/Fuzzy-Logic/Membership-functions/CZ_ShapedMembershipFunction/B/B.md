# B

# B (Get metódus)

Lekéri a csökkenő intervallum végének paraméterét.

```cpp
double  B()
```

Visszatérési érték

A csökkenő intervallum végének paramétere.

# B (Set metódus)

Beállítja a csökkenő intervallum végének paraméterét.

```cpp
void  B(
   const double  b      // decreasing interval end parameter
   )
```

Paraméterek

b

[in] A csökkenő intervallum végének paramétere.
