# A

# A (Get metódus)

Lekéri a csökkenő intervallum kezdetének paraméterét.

```cpp
double  A()
```

Visszatérési érték

A csökkenő intervallum kezdetének paramétere.

# A (Set metódus)

Beállítja a csökkenő intervallum kezdetének paraméterét.

```cpp
void  A(
   const double  a      // decreasing interval start parameter
   )
```

Paraméterek

a

[in] A csökkenő intervallum kezdetének paramétere.
