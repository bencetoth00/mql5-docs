# B

# B (Get metódus)

Lekéri a tagsági függvény középpontját.

```cpp
double  B()
```

Visszatérési érték

A tagsági függvény középpontjának értéke.

# B (Set metódus)

Beállítja a tagsági függvény középpontjának értékét.

```cpp
void  B(
   const double  b      // function center value
   )
```

Paraméterek

b

[in]  A tagsági függvény középpontjának értéke.
