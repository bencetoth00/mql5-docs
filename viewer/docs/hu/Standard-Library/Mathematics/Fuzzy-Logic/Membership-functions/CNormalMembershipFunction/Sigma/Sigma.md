# Sigma (lekérő metódus)

Lekéri a tagsági függvény görbületi paraméterét.

```cpp
double  Sigma()
```

Visszatérési érték

A tagsági függvény görbületi paraméterének értéke.

# Sigma (beállító metódus)

Beállítja a tagsági függvény görbületi paraméterének értékét.

```cpp
void  Sigma(
   const double  sigma      // curvature parameter value
   )
```

Paraméterek

sigma

[in] A tagsági függvény görbületi paramétere.
