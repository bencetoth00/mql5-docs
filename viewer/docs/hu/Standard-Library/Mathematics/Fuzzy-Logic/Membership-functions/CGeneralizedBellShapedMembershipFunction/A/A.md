# A (Get metódus)

Lekéri a tagsági függvény koncentrációs arányát.

```cpp
double  A()
```

Visszatérési érték

A koncentrációs arány értéke.

# A (Set metódus)

Beállítja a tagsági függvény koncentrációs arányát.

```cpp
void  A(
   const double  a      // concentration ratio value
   )
```

Paraméterek

a

[in]  A tagsági függvény koncentrációs aránya.
