# C

# C (Get metódus)

Lekéri a tagsági függvény maximális koordinátáját.

```cpp
double  C()
```

Visszatérési érték

A tagsági függvény maximális koordinátája.

# C (Set metódus)

Beállítja a tagsági függvény maximális koordinátáját.

```cpp
void  C(
   const double  c      // maximum coordinate value
   )
```

Paraméterek

c

[in]  A maximális koordináta értéke.
