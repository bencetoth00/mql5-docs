# B (Get metódus)

Lekéri a tagsági függvény meredekségi arányát.

```cpp
double  B()
```

Visszatérési érték

A meredekségi arány értéke.

 

# B (Set metódus)

Beállítja a tagsági függvény meredekségi arányát.

```cpp
void  B(
   const double  b      // slope ratio value
   )
```

Paraméterek

b

[in]  A tagsági függvény meredekségi aránya.
