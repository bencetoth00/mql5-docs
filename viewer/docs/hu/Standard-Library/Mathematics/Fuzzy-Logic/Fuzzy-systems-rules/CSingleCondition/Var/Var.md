# Var

# Var (Get metódus)

Lekéri az adott feltételhez tartozó fuzzy változót. 

```cpp
INamedVariable* Var()
```

Visszatérési érték

Az adott feltétel fuzzy változója.

# Var (Set metódus)

Beállítja az adott feltétel fuzzy változóját.

```cpp
void  Var(
   INamedVariable*&  value      // a fuzzy variable for the given condition
   )
```

Paraméterek

value

[in]  A fuzzy változó.
