# Term (lekérő metódus)

Lekéri az adott feltételhez tartozó fuzzy kifejezést.  

```cpp
INamedValue* Term()
```

Visszatérési érték

Az adott feltételhez tartozó fuzzy kifejezés.

# Term (beállító metódus)

Beállítja az adott feltételhez tartozó fuzzy kifejezést.

```cpp
void  Term(
   INamedValue*&  value      // fuzzy term for the given condition
   )
```

Paraméterek

value

[in]  Az adott feltételhez tartozó fuzzy kifejezés.
