Lekéri a Mamdani-fuzzy szabály súlyát. 

```cpp
double  Weight()
```

# Weight (Set metódus)

Beállítja a Mamdani-fuzzy szabály súlyát.

```cpp
void  Weight(
   const double  value      // weight of a Mamdani fuzzy rule
   )
```

Paraméterek

value

[in]  A Mamdani-fuzzy szabály súlya.
