# Conclusion (lekérő metódus)

Lekéri a fuzzy szabály következtetését.  

```cpp
CSingleConditon*  Conclusion()
```

# Conclusion (beállító metódus)

Beállítja a fuzzy szabály következtetését.

```cpp
virtual void  Conclusion(
   CSingleConditon*  value      // conclusion of a fuzzy rule
   )
```

Paraméterek

value

[in]  A fuzzy szabály következtetése.
