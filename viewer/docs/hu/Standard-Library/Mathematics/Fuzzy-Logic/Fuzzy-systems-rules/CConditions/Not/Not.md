# Not

# Not (Get metódus)

Lekéri azt a jelzőt, amely megadja, hogy alkalmazni kell-e ezeknek a feltételeknek a tagadását. 

```cpp
bool Not()
```

Visszatérési érték

A jelző értéke.

# Not (Set metódus)

Beállítja azt a jelzőt, amely megadja, hogy alkalmazni kell-e ezeknek a feltételeknek a tagadását.

```cpp
void  Not(
   bool  not      // flag value
   )
```

Paraméterek

not

[in]  A jelző értéke.
