# ParseRule

```cpp
CMamdaniFuzzyRule*  ParseRule(
   const string  rule      // string representation of a fuzzy rule
   )
```

Paraméterek

rule

[in]  A fuzzy Mamdani-szabály szöveges reprezentációja.

Visszatérési érték

Fuzzy Mamdani-szabály.
