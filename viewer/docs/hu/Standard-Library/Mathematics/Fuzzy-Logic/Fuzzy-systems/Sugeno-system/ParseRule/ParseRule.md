# ParseRule


Fuzzy Sugeno-szabályt hoz létre a megadott karakterlánc alapján.

```cpp
CSugenoFuzzyRule*  ParseRule(
   const string  rule      // string representation of a fuzzy Sugeno rule
   )
```

Paraméterek

rule

[in]  A fuzzy Sugeno-szabály szöveges reprezentációja.

Visszatérési érték

Fuzzy Sugeno-szabály.
