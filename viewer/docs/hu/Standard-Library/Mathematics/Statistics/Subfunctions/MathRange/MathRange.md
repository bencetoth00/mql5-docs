# MathRange


Kiszámítja a tömbelemek minimumát és maximumát.

```cpp
bool  MathRange(
   const double&  array[],  // array of values
   double&        min,      // minimum value
   double&        max       // maximum value
   )
```

Paraméterek

array[]

[in] Az értékeket tartalmazó tömb. 

min

[out] A minimális érték tárolására szolgáló változó.

max

[out] A maximális érték tárolására szolgáló változó.

Visszatérési érték

Siker esetén true, ellenkező esetben false értéket ad vissza.
