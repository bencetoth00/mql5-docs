# MathBetaLog


Kiszámítja a bétafüggvény logaritmusát az a és b valós argumentumokra.

```cpp
double  MathBetaLog(
   const double  a,      // the first argument of the function
   const double  b       // the second argument of the function
   )
```

Paraméterek

a

[in] A függvény a argumentuma. 

b

[in] A függvény b argumentuma. 

Visszatérési érték

A függvény logaritmusa.
