# MathAverageDeviation


A függvény kiszámítja a tömb elemeinek átlagos abszolút eltérését.

```cpp
double  MathAverageDeviation(
   const double&  array[]   // array of values
   )
```

Paraméterek

array[]

[in] Értékeket tartalmazó tömb. 

Visszatérési érték

A tömb elemeinek átlagos abszolút eltérése.
