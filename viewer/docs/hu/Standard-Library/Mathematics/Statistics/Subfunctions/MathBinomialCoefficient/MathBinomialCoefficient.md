# MathBinomialCoefficient


Kiszámítja a binomiális együtthatót: C(n,k)=n!/(k!\*(n-k)!).

```cpp
long  MathBinomialCoefficient(
   const int  n,      // the total number of elements
   const int  k       // the number of elements in combination
   )
```

Paraméterek

n

[in] Az elemek száma. 

k

[in]  Az egy kombinációban szereplő elemek száma. 

Visszatérési érték

A kiválasztott N elem K elemű kombinációinak száma.
