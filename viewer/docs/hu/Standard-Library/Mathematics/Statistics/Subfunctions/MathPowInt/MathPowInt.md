# MathPowInt


A számot a megadott egész kitevőre emeli.

```cpp
double  MathPowInt(
   const double  x,      // value of the number
   const int     power   // power to raise to
   )
```

Paraméterek

x

[in]  A hatványozandó, dupla pontosságú lebegőpontos szám.

power

[in]  A kitevőt meghatározó egész szám. 

Visszatérési érték

Az x szám power-edik hatványa.
