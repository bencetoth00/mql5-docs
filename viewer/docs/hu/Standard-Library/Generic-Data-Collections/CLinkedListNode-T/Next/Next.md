# Next

# Next (Get metódus)

Visszaadja a következő csomópontra mutató pointert.

```cpp
CLinkedListNode<T>* Next();
```

Visszatérési érték

Pointer a következő csomópontra.

# Next (Set metódus)

Beállítja a következő csomópontra mutató pointert.

```cpp
void Next(
   CLinkedListNode<T>*  value     // a pointer to the next node
   );
```

Paraméterek

*value

[in]  Pointer a következő csomópontra.
