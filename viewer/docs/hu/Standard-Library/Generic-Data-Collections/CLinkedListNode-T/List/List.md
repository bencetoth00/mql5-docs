# List (lekérő metódus)

Visszaad egy pointert a CLinkedList<T> listára.

```cpp
CLinkedList<T>* List();
```

Visszatérési érték

Pointer a CLinkedList<T> láncolt listára.

# List (beállító metódus)

Beállít egy pointert a CLinkedList<T> listára.

```cpp
void List(
   CLinkedList<T>*  value     // a pointer to the list
   );
```

Paraméterek

\*value

[in]  Pointer a CLinkedList<T> láncolt listára.
