# Previous (lekérő metódus)

Visszaad egy pointert az előző csomópontra.

```cpp
CLinkedListNode<T>* Previous();
```

Visszatérési érték

Pointer az előző csomópontra.

# Previous (beállító metódus)

Beállít egy pointert az előző csomópontra.

```cpp
void Previous(
   CLinkedListNode<T>*  value     // a pointer to the previous node
   );
```

Paraméterek

\*value

[in]  Pointer az előző csomópontra.
