# Contains


Megállapítja, hogy a verem tartalmaz-e a megadott értékű elemet.

```cpp
bool Contains(
   T  item     // the search value
   );
```

Paraméterek

item

[in]  A keresett érték.

Visszatérési érték

true értéket ad vissza, ha a veremben megtalálható a megadott értékű elem, egyébként false értéket.
