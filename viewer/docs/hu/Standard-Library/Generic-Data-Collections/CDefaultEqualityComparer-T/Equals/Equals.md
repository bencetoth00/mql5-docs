# Equals


Összehasonlít két T típusú értéket.

```cpp
bool Equals(
   T  x,     // the first value
   T  y      // the second value
   );
```

Paraméterek

x

[in]  Az első összehasonlítandó érték.

y

[in]  A második összehasonlítandó érték.

Visszatérési érték

true értéket ad vissza, ha az értékek egyenlők, egyébként false értéket.
