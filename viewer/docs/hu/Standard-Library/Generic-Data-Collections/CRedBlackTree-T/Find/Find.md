# Find


Megkeresi a megadott érték előfordulását a piros-fekete fában.

```cpp
CRedBlackTreeNode<T>* Find(
   T  value     // the search value
   );
```

Paraméterek

value

[in]  A keresett érték.

Visszatérési érték

Siker esetén a keresett értéket tartalmazó megtalált csomópontra mutató pointer, egyébként NULL.
