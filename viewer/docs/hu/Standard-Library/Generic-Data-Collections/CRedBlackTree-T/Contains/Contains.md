# Contains


Megállapítja, hogy a piros-fekete fa tartalmaz-e a megadott értékű elemet.

```cpp
bool Contains(
   T  item     // the search value
   );
```

Paraméterek

item

[in]  A keresett érték.

Visszatérési érték

true értéket ad vissza, ha a piros-fekete fában megtalálható a megadott értékű elem, egyébként false értéket.
