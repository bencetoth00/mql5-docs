# FindLast


Megkeresi a megadott érték utolsó előfordulását a láncolt listában.

```cpp
CLinkedListNode<T>* FindLast(
   T  value     // the search value
   );
```

Paraméterek

value

[in]  A keresett érték.

Visszatérési érték

Siker esetén a keresett értéket tartalmazó utolsó megtalált csomópontra mutató pointer, egyébként NULL.
