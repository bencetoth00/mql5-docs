# Find


Megkeresi a megadott érték első előfordulását a láncolt listában.

```cpp
CLinkedListNode<T>* Find(
   T  value     // the search value
   );
```

Paraméterek

value

[in]  A keresett érték.

Visszatérési érték

Siker esetén a keresett értéket tartalmazó első megtalált csomópontra mutató pointer, egyébként NULL.
