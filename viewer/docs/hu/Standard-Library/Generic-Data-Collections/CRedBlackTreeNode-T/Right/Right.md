# Right (Get metódus)

Pointert ad vissza a jobb oldali csomópontra.

```cpp
CRedBlackTreeNode<T>* Right();
```

Visszatérési érték

Pointer a jobb oldali csomópontra.

# Right (Set metódus)

Beállítja a jobb oldali csomópontra mutató pointert.

```cpp
void Right(
   CRedBlackTreeNode<T>*  node     // a pointer to the right node
   );
```

Paraméterek

*node

[in] A jobb oldali csomópontra mutató pointer.
