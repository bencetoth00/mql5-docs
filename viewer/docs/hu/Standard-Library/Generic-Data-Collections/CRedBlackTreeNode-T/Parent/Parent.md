# Parent

# Parent (lekérő metódus)

Visszaad egy mutatót a szülőcsomópontra.

```cpp
CRedBlackTreeNode<T>* Parent();
```

Visszatérési érték

A szülőcsomópontra mutató pointer.

# Parent (beállító metódus)

Beállítja a szülőcsomópontra mutató pointert.

```cpp
void Parent(
   CRedBlackTreeNode<T>*  node     // a pointer to the parent node
   );
```

Paraméterek

\*node

[in] A szülőcsomópontra mutató pointer.
