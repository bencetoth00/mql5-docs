# Left

# Left (Get metódus)

Pointert ad vissza a bal oldali csomópontra.

```cpp
CRedBlackTreeNode<T>* Left();
```

Visszatérési érték

Pointer a bal oldali csomópontra.

# Left (Set metódus)

Beállítja a bal oldali csomópontra mutató pointert.

```cpp
void Left(
   CRedBlackTreeNode<T>*  node     // a pointer to the left node
   );
```

Paraméterek

*node

[in] A bal oldali csomópontra mutató pointer.
