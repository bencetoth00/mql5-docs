# ContainsKey


Megállapítja, hogy a hash-tábla tartalmaz-e a megadott kulcsú kulcs/érték párt.

```cpp
bool ContainsKey(
   TKey  key     // key
   );
```

Paraméterek

key

[in]  A kulcs.

Visszatérési érték

true értéket ad vissza, ha a hash-tábla tartalmaz a megadott kulcsú kulcs/érték párt, egyébként false értéket.
