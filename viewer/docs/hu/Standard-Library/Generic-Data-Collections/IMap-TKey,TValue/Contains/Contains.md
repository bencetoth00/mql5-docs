# Contains


Megállapítja, hogy a gyűjtemény tartalmaz-e a megadott kulcsú kulcs/érték párt.

```cpp
bool Contains(
   TKey    key,      // key
   TValue  value     // value
   );
```

Paraméterek

key

[in]  A kulcs.

value

[in]  Az érték.

Visszatérési érték

true értéket ad vissza, ha a gyűjtemény tartalmaz a megadott kulcsú és értékű kulcs/érték párt, egyébként false értéket.
