# Insert


Elemet szúr be a listába a megadott indexen.

```cpp
bool Insert(
   const int  index,     // index to insert at
   T          item       // the value to be inserted
   );
```

Paraméterek

index

[in]  A beszúrás indexe.

item

[in] A megadott indexre beszúrandó érték.

Visszatérési érték

Sikeres végrehajtás esetén true, egyébként false.
