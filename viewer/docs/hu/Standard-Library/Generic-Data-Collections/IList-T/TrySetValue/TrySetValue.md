# TrySetValue


Módosítja a listaelem értékét a megadott indexen.

```cpp
bool TrySetValue(
   const int  index,     // element index
   T          value      // new value
   );
```

Paraméterek

index

[in]  A listaelem indexe.

value

[in] A megadott listaelemhez rendelendő új érték.

Visszatérési érték

Sikeres végrehajtás esetén true, egyébként false.
