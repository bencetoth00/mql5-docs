# ContainsValue


Megállapítja, hogy a rendezett hash-tábla tartalmaz-e a megadott értékű kulcs/érték párt.

```cpp
bool ContainsValue(
   TValue  value     // value
   );
```

Paraméterek

value

[in]  Az érték.

Visszatérési érték

true értéket ad vissza, ha a rendezett hash-tábla tartalmaz a megadott értékű kulcs/érték párt, egyébként false értéket.
