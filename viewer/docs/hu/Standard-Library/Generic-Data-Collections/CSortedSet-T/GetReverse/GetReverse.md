# GetReverse


Lekéri az aktuális rendezett halmaz másolatát, amelyben az elemek fordított sorrendben szerepelnek.

```cpp
bool GetReverse(
   T&  array[]     // an array for writing
   );
```

Paraméterek

&array[]

[out] Egy tömb, amelybe az adatok kerülnek.

Visszatérési érték

Sikeres végrehajtás esetén true, egyébként false.
