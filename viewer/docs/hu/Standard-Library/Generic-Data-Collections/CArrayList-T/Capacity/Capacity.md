# Capacity

# Capacity (Get metódus)

Visszaadja a lista aktuális kapacitását.

```cpp
int Capacity();
```

Visszatérési érték

A lista aktuális kapacitása.

# Capacity (Set metódus)

Beállítja a lista aktuális kapacitását.

```cpp
void Capacity(
   const int  capacity     // capacity value
   );
```

Paraméterek

capacity

[in]  A kapacitás új értéke.
