# RemoveRange


Eltávolít egy elemtartományt a listából.

```cpp
bool RemoveRange(
   const int  start_index,     // the starting index
   const int  count            // the number of elements
   );
```

Paraméterek

start\_index

[in] A törlés kezdőindexe.

count

[in]  A törlendő elemek száma.

Visszatérési érték

Siker esetén true, ellenkező esetben false értéket ad vissza.
