# TrySetValue


Beállítja a listaelem értékét a megadott indexen.

```cpp
bool TrySetValue(
   const int  index,     // index
   T          value      // element value
   );
```

Paraméterek

index

[in]  Annak a listaelemnek az indexe, amelynek az értékét be kell állítani.

value

[in]  A listaelem beállítandó értéke.

Visszatérési érték

Siker esetén true, ellenkező esetben false értéket ad vissza.
