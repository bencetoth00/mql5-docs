# Equals


Összehasonlítja az aktuális objektumot a megadott értékkel.

```cpp
bool Equals(
   T  value     // the value to compare
   );
```

Paraméterek

value

[in]  Az aktuális objektummal összehasonlítandó érték.

Visszatérési érték

true értéket ad vissza, ha az objektumok egyenlők, egyébként false értéket.
