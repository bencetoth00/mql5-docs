# GetX


Lekéri az összes görbepont X értékét a tömbbe.

```cpp
void  GetX(
   double&  x[]      // array for writing X values
   )
```

Paraméterek

x[]

[out]  Tömb, amelybe az összes görbepont X értéke kerül.

Megjegyzés

A görbe minden pontját egy X és egy Y érték határozza meg. Ezek nem pixelkoordináták a [CGraphic](../../CGraphic/CGraphic.md) osztályban történő rajzoláshoz.
