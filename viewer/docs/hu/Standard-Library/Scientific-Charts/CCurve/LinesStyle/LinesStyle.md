# LinesStyle

# LinesStyle (Get metódus)

Visszaadja a vonallal kirajzolt görbe vonalstílusát.

```cpp
ENUM_LINE_STYLE  LinesStyle()
```

Visszatérési érték

A vonal stílusa.

# LinesStyle (Set metódus)

Beállítja a vonallal kirajzolt görbe vonalstílusát.

```cpp
void  LinesStyle (
   ENUM_LINE_STYLE  style      // line style
   )
```

Paraméterek

style

[in]  A vonal stílusa.
