# GetY


Lekéri az összes görbepont Y értékét a tömbbe.

```cpp
void  GetY(
   double&  y[]      // array for writing Y values
   )
```

Paraméterek

y[]

[out]  Tömb, amelybe az összes görbepont Y értéke kerül.

Megjegyzés

A görbe minden pontját egy X és egy Y érték határozza meg. Ezek nem pixelkoordináták a [CGraphic](../../CGraphic/CGraphic.md) osztályban történő rajzoláshoz.
