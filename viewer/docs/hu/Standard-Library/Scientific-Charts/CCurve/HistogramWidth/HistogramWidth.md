# HistogramWidth (lekérő metódus)

Visszaadja a hisztogram megjelenítésekor használt oszlopok szélességét.

```cpp
int  HistogramWidth()
```

Visszatérési érték

Az oszlop szélessége képpontban.

# HistogramWidth (beállító metódus)

Beállítja a hisztogram megjelenítésekor használt oszlopok szélességét.

```cpp
void  HistogramWidth(
   const int  width      // column width
   )
```

Paraméterek

width

[in]  Az oszlop szélessége képpontban.
