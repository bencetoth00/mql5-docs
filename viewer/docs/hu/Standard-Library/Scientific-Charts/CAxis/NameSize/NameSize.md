# NameSize

# NameSize (Get metódus)

Visszaadja a tengelynév betűméretét.

```cpp
int  NameSize()
```

Visszatérési érték

A tengelynév betűmérete.

# NameSize (Set metódus)

Beállítja a tengelynév betűméretét.

```cpp
void  NameSize(
   const int  size      // font size of the axis name
   )
```

Paraméterek

size

[in] A tengelynév betűmérete.
