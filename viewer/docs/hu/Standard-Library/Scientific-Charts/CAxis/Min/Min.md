# Min

# Min (Get metódus)

Visszaadja a tengely minimális értékét.

```cpp
double  Min()
```

Visszatérési érték

A tengely minimális értéke.

# Min (Set metódus)

Beállítja a tengely minimális értékét.

```cpp
void  Min(
   const double  min      // minimum value
   )
```

Paraméterek

min

[in]  A minimális érték.
