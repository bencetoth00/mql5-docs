# ValuesFormat (Get metódus)

Visszaadja a tengely számainak formátumát.

```cpp
string  ValuesFormat()
```

Visszatérési érték

A számformátum.

# ValuesFormat (Set metódus)

Beállítja a tengely számainak formátumát.

```cpp
void  ValuesFormat(
   const string  format      // format of the axis numbers
   )
```

Paraméterek

format

[in]  A tengelyszámok formátuma.
