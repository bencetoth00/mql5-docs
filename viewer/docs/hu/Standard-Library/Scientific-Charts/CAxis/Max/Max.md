# Max

# Max (Get metódus)

Visszaadja a tengely maximális értékét.

```cpp
double  Max()
```

Visszatérési érték

A tengely maximális értéke.

# Max (Set metódus)

Beállítja a tengely maximális értékét.

```cpp
void  Max(
   const double  max      // maximum value
   )
```

Paraméterek

max

[in]  A tengely maximális értéke.
