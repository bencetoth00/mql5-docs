# ValuesSize (Get metódus)

Visszaadja a tengely számainak méretét.

```cpp
int  ValuesSize()
```

Visszatérési érték

A tengelyszámok mérete.

# ValuesSize (Set metódus)

Beállítja a tengely számainak méretét.

```cpp
void  ValuesSize(
   const int  size      // size of the axis numbers
   )
```

Paraméterek

size

[in]  A tengelyszámok mérete.
