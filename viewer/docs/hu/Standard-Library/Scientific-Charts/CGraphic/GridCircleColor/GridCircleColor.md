# GridCircleColor (Get metódus)

Visszaadja a rácscsomópontok pontjainak színét.

```cpp
color  GridCircleColor()
```

# GridCircleColor (Set metódus)

```cpp
void  GridCircleColor(
   const color  clr      // dot color
   )
```

Paraméterek

clr

[in]  A pontok színe.
