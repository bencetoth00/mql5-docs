# IndentUp (Get metódus)

Lekéri a diagram felső szélétől mért margót.

```cpp
int  IndentUp()
```

Visszatérési érték

A margó mérete pixelben.

# IndentUp (Set metódus)

Beállítja a diagram felső szélétől mért margót.

```cpp
void  IndentUp(
   const int  up      // indent size
   )
```

Paraméterek

up

[in]  A margó értéke pixelben.
