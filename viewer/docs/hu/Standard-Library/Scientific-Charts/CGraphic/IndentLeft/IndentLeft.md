# IndentLeft (Get metódus)

Lekéri a diagram bal szélétől mért margót.

```cpp
int  IndentLeft()
```

Visszatérési érték

A margó mérete pixelben.

# IndentLeft (Set metódus)

Beállítja a diagram bal szélétől mért margót.

```cpp
void  IndentLeft(
   const int  left      // indent size
   )
```

Paraméterek

left

[in]  A margó mérete pixelben.
