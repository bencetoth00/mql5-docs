# BackgroundColor

# BackgroundColor (Get metódus)

Visszaadja a háttér színét.

```cpp
color  BackgroundColor()
```

 

# BackgroundColor (Set metódus)

Beállítja a háttér színét.

```cpp
void  BackgroundColor(
   const color  clr      // background color
   )
```

Paraméterek

clr

[in]  A háttér színe.
