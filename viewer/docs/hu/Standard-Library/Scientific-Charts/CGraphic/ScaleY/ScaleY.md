# ScaleY


Az Y tengely mentén pixelkoordinátára skálázza az értéket.

```cpp
virtual int  ScaleY(
   double  y      // value by Y axis
   )
```

Paraméterek

y

[in]  Valós érték az Y tengely mentén.

Visszatérési érték

Az érték pixelben.

Megjegyzés

Valós értéket skáláz pixelkoordinátára a diagramon való megjelenítéshez.
