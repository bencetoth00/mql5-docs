# GridBackgroundColor (Get metódus)

Visszaadja a rács háttérszínét.

```cpp
color  GridBackgroundColor()
```

Visszatérési érték

A rács háttérszíne.

# GridBackgroundColor (Set metódus)

Beállítja a rács háttérszínét.

```cpp
void  GridBackgroundColor(
   const color  clr      // grid background color
   )
```

Paraméterek

clr

[in]  A rács háttérszíne.
