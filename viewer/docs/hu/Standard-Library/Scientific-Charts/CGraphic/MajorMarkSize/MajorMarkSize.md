# MajorMarkSize (Get metódus)

Visszaadja a koordinátatengelyek skálabeosztásainak méretét.

```cpp
int  MajorMarkSize()
```

 

# MajorMarkSize (Set metódus)

Beállítja a koordinátatengelyek skálabeosztásainak méretét.

```cpp
void  MajorMarkSize(
   const int  size      // tick size
   )
```

Paraméterek

size

[in]  A beosztás mérete pixelben.
