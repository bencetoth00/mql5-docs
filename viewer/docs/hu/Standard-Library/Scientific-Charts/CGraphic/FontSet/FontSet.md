# FontSet


Beállítja az aktuális betűtípus paramétereit.

```cpp
bool  FontSet(
   const string  name,        // name
   const int     size,        // size
   const uint    flags=0,     // flags
   const uint    angle=0      // angle
   )
```

Paraméterek

name

[in]  Név.

size

[in]  Méret.

flags=0

[in]  Jelzők.

angle=0

[in]  Szög.

Visszatérési érték

Siker esetén true, ellenkező esetben false.
