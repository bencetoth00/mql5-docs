# IndentDown (Get metódus)

Lekéri a diagram alsó szélétől mért margót.

```cpp
int  IndentDown()
```

Visszatérési érték

A margó mérete pixelben.

# IndentDown (Set metódus)

Beállítja a diagram alsó szélétől mért margót.

```cpp
void  IndentDown(
   const int  down      // indent size
   )
```

Paraméterek

down

[in]  A margó mérete pixelben.
