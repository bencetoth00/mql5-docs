# ScaleX


Az X tengely mentén pixelkoordinátára skálázza az értéket.

```cpp
virtual int  ScaleX(
   double  x      // value by X axis
   )
```

Paraméterek

x

[in]  Valós érték az X tengely mentén.

Visszatérési érték

Az érték pixelben.

Megjegyzés

Valós értéket skáláz pixelkoordinátára a diagramon való megjelenítéshez.
