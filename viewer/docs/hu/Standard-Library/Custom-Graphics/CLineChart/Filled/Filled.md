# Filled


Beállítja, hogy ki kell-e tölteni az adatsor által meghatározott görbe alatti területet.

```cpp
 void  Filled(
   const bool  flag=true,  // flag
   )
```

Paraméterek

flag=true

[in] Jelzőérték:

- true — kitölti a görbe alatti területet
- false — nem tölti ki a görbe alatti területet
