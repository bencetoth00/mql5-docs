# CalcArea


Kiszámítja az adatsor által meghatározott görbe alatti területet.

```cpp
 double  CalcArea(
   const uint  index,  // index
   )
```

Paraméterek

index

[in] Az adatsor indexe – a hozzáadás sorszáma, 0-tól kezdve.   

Visszatérési érték

Az adatsor által meghatározott görbe által határolt alakzat területe.
