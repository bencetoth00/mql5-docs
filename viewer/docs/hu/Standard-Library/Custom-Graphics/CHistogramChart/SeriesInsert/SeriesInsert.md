# SeriesInsert


Adatsort szúr be a diagramba.

```cpp
 bool  SeriesInsert(
   const uint    pos,       // index
   const double&  value[],  // values
   const string  descr,     // label
   const uint    clr,       // color
   )
```

Paraméterek

pos

[in] A beszúrás indexe.

value[]

[in] Az adatsor. 

descr

[in] Az adatsor címkéje. 

clr

[in] Az adatsor megjelenítési színe. 

Visszatérési érték

Siker esetén true, egyébként false.
