# DescriptorUpdate


Frissíti az adatsor leírójának értékét a megadott pozícióban.

```cpp
 bool  DescriptorUpdate(
   const uint    pos,    // index
   const string  descr,  // value
   )
```

Paraméterek

pos

[in] Az adatsor indexe – a hozzáadás sorszáma, 0-tól kezdve.

descr

[in] A leíró értéke.

Visszatérési érték

Siker esetén true, ellenkező esetben false.
