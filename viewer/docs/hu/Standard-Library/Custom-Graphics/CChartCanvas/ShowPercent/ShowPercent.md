# ShowPercent


Beállítja a százalékok láthatósági jelzőjét (FLAG\_SHOW\_PERCENT).                            

```cpp
 void  ShowPercent(
   const bool  flag,  // flag value
   )
```

Paraméterek

flag

[in] Jelzőérték:

- true — a százalék láthatóvá válik.
- false — a százalék láthatatlanná válik.
