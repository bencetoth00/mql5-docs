# ShowScaleLeft


Beállítja a bal oldali skála láthatósági jelzőjét (FLAG\_SHOW\_SCALE\_LEFT).                            

```cpp
 void  ShowScaleLeft(
   const bool  flag,  // flag value
   )
```

Paraméterek

flag

[in] Jelzőérték:

- true — a bal oldali skála láthatóvá válik.
- false — a bal oldali skála láthatatlanná válik.
