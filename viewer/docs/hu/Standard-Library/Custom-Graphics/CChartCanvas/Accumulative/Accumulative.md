# Accumulative


Beállítja az adatsor értékfelhalmozási jelzőjét.                                           

```cpp
 void  Accumulative(
   const bool  flag=true,  // flag value
   )
```

Paraméterek

flag=true

[in] Jelzőérték:

- true — az adatsor aktuális értékét az összes korábbi érték összege váltja fel.
- false — az adatsorok rajzolásának normál módja.
