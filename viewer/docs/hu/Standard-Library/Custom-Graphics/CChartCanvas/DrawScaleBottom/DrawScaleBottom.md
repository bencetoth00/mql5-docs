# DrawScaleBottom


Az alsó értékskála újrarajzolására szolgáló virtuális metódus.                                          

```cpp
 virtual int  DrawScaleBottom(
   const bool  draw,  // flag
   )
```

Paraméterek

draw

[in] Jelző, amely meghatározza, hogy újra kell-e rajzolni a skálát. 

Visszatérési érték

Az értékskála magassága.
