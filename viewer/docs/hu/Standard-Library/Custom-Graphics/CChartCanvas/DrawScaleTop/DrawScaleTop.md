# DrawScaleTop


A felső értékskála újrarajzolására szolgáló virtuális metódus.                                              

```cpp
 virtual int  DrawScaleTop(
   const bool  draw,  // flag
   )
```

Paraméterek

draw

[in] Jelző, amely meghatározza, hogy újra kell-e rajzolni a skálát. 

Visszatérési érték

Az értékskála magassága.
