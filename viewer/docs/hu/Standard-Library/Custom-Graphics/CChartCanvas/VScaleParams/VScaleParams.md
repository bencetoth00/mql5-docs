# VScaleParams


Beállítja a függőleges értékskála paramétereit.

```cpp
 void  VScaleParams(
   const double  max,   // maximum
   const double  min,   // minimum
   const uint    grid,  // number of divisions
   )
```

Paraméterek

max

[in] A maximális érték.

min

[in] A minimális érték. 

grid

[in] A skála osztásainak száma.
