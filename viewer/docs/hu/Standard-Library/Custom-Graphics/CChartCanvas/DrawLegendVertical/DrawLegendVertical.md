# DrawLegendVertical


Függőleges jelmagyarázatot rajzol.

```cpp
 int  DrawLegendVertical(
   const int  w,  // width
   const int  h,  // height
   )
```

Paraméterek

w

[in] A jelmagyarázat szövegének maximális szélessége.

h

[in] A jelmagyarázat szövegének maximális magassága. 

Visszatérési érték

A jelmagyarázat szélessége pixelben.
