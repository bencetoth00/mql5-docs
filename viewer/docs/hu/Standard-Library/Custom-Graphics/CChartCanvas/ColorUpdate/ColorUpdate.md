# ColorUpdate


Frissíti az adatsor színét (a megadott pozícióban).

```cpp
 bool  ColorUpdate(
   const uint  pos,  // index
   const uint  clr,  // color
   )
```

Paraméterek

pos

[in] Az adatsor indexe – a hozzáadás sorszáma, 0-tól kezdve. 

clr

[in] A szín értéke.

Visszatérési érték

Siker esetén true, egyébként false.
