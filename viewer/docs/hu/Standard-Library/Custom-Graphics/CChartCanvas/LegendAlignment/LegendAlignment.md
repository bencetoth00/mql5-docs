# LegendAlignment


Beállítja a jelmagyarázat szövegének igazítását.

```cpp
 void  LegendAlignment(
   const ENUM_ALIGNMENT  value,  // flag
   )
```

Paraméterek

value

[in] Az ENUM\_ALIGNMENT felsorolás alábbi értékeinek egyike:

- ALIGNMENT\_LEFT — balra igazítás.
- ALIGNMENT\_TOP — felülre igazítás.
- ALIGNMENT\_RIGHT — jobbra igazítás.
- ALIGNMENT\_BOTTOM — alulra igazítás.
