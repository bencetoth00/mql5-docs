# DrawScaleLeft


A bal oldali értékskála újrarajzolására szolgáló virtuális metódus.                                              

```cpp
 virtual int  DrawScaleLeft(
   const bool  draw,  // flag
   )
```

Paraméterek

draw

[in] Jelző, amely meghatározza, hogy újra kell-e rajzolni a skálát. 

Visszatérési érték

Az értékskála szélessége.
