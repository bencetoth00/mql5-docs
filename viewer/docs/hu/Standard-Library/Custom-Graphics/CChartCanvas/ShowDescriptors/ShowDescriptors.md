# ShowDescriptors


Beállítja a leírók láthatósági jelzőjét (FLAG\_SHOW\_DESCRIPTORS).                         

```cpp
 void  ShowDescriptors(
   const bool  flag,    // flag value
   )
```

Paraméterek

flag

[in] Jelzőérték:

- true — a leíró láthatóvá válik.
- false — a leíró láthatatlanná válik.
