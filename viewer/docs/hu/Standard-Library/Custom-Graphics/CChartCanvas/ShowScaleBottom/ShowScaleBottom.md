# ShowScaleBottom


Beállítja az alsó skála láthatósági jelzőjét (FLAG\_SHOW\_SCALE\_BOTTOM).                        

```cpp
 void  ShowScaleBottom(
   const bool  flag,     // flag value
   )
```

Paraméterek

flag

[in] Jelzőérték:

- true — az alsó skála láthatóvá válik.
- false — az alsó skála láthatatlanná válik.
