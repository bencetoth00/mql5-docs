# DrawLegendHorizontal


Vízszintes jelmagyarázatot rajzol.                                

```cpp
 int  DrawLegendHorizontal(
   const int  w,  //
   const int  h,  //
   )
```

Paraméterek

w

[in] A jelmagyarázat szövegének maximális szélessége. 

h

[in] A jelmagyarázat szövegének maximális magassága. 

Visszatérési érték

A jelmagyarázat magassága pixelben.
