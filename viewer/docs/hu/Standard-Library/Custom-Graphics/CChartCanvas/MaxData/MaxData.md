# MaxData (lekérő metódus)

Visszaadja az engedélyezett adatsorok maximális számát.

```cpp
 uint  MaxData()
```

Visszatérési érték

Az adatsorok maximális száma.

# MaxData (beállító metódus)

Beállítja az engedélyezett adatsorok maximális számát.                                    

```cpp
 void  MaxData(
   const uint  value,  // amount of data
   )
```

Paraméterek

value

[in] Az adatsorok maximális száma.
