# ShowScaleTop


Beállítja a felső skála láthatósági jelzőjét (FLAG\_SHOW\_SCALE\_TOP).                          

```cpp
 void  ShowScaleTop(
   const bool  flag,  // flag value
   )
```

Paraméterek

flag

[in] Jelzőérték:

- true — a felső skála láthatóvá válik.
- false — a felső skála láthatatlanná válik.
