# VScaleMin

# VScaleMin (lekérő metódus)

Visszaadja az értékek függőleges skálájának minimumát.

```cpp
 double  VScaleMin()
```

Visszatérési érték

A függőleges skála minimális értéke.

# VScaleMin (beállító metódus)

Beállítja az értékek függőleges skálájának minimumát.                  

```cpp
 void  VScaleMin(
   const double  value,    // value on the vertical scale
   )
```

Paraméterek

value

[in] A minimális érték.
