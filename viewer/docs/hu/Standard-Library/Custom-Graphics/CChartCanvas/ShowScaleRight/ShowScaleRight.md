# ShowScaleRight


Beállítja a jobb oldali skála láthatósági jelzőjét (FLAG\_SHOW\_SCALE\_RIGHT).                           

```cpp
 void  ShowScaleRight(
   const bool  flag,  // flag value
   )
```

Paraméterek

flag

[in] Jelzőérték:

- true — a jobb oldali skála láthatóvá válik.
- false — a jobb oldali skála láthatatlanná válik.
