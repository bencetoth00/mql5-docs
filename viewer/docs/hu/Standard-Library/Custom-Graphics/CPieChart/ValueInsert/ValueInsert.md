# ValueInsert


Új értéket szúr be a kördiagram megadott pozíciójára.

```cpp
 bool  ValueInsert(
   const uint    pos,    // index
   const double  value,  // value
   const string  descr,  // label
   const uint    clr,    // color
   )
```

Paraméterek

pos

[in] A beszúrás indexe.

value

[in] Az érték.

descr

[in] Az érték címkéje. 

clr

[in] Az érték színe.

Visszatérési érték

Siker esetén true, egyébként false.
