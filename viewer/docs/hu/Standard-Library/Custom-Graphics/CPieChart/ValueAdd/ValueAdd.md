# ValueAdd


Új értéket ad hozzá a kördiagramhoz (a végére).

```cpp
 bool  ValueAdd(
   const double  value,  // value
   const string  descr,  // label
   const uint    clr,    // color
   )
```

Paraméterek

value

[in] Az érték.

descr

[in] Az érték címkéje.

clr

[in] Az érték színe.

Visszatérési érték

Siker esetén true, egyébként false.
