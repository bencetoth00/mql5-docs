# SeriesSet


Beállítja a kördiagramon megjelenítendő értékek adatsorát.

```cpp
 bool  SeriesSet(
   const double&  value[],  // values
   const string&  text[],   // labels
   const uint&    clr[],    // color
   )
```

Paraméterek

value[]

[in] Az értékek tömbje.

text[]

[in] Az értékcímkék tömbje.

clr[]

[in] Az értékszínek tömbje.

Visszatérési érték

Siker esetén true, egyébként false.
