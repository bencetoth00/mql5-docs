# LineVertical


Függőleges vonalszakaszt rajzol.

```cpp
void  LineVertical(
   int         x,       // X coordinate
   int         y1,      // Y coordinate
   int         y2,      // Y coordinate
   const uint  clr      // color
   );
```

Paraméterek

x

[in]  A szakasz X koordinátája.

y1

[in]  A szakasz első pontjának Y koordinátája.

y2

[in]  A szakasz második pontjának Y koordinátája.

clr

[in]  Szín ARGB formátumban.
