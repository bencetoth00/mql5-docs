# LineStyleSet


Beállítja a vonal stílusát.

```cpp
void  LineStyleSet(
   const uint  style      // style
   );
```

Paraméterek

style

[in]  A vonal stílusa.

Megjegyzés

A bemeneti paraméter az ENUM\_LINE\_STYLE felsorolás bármely értékét felveheti. Egyéni vonalrajzolási stílus is létrehozható.
