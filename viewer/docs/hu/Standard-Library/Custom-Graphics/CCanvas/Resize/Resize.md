# Resize


Átméretezi a grafikus erőforrást.

```cpp
bool  Resize(
   const int  width,      // width
   const int  height      // height
   );
```

Paraméterek

width

[in]  A grafikus erőforrás új szélessége.

height

[in]  A grafikus erőforrás új magassága.

Visszatérési érték

Siker esetén true, egyébként false.

Megjegyzés

Átméretezéskor az előző kép nem kerül mentésre.
