# FillCircle


Kitöltött kört rajzol.

```cpp
void  FillCircle(
   int         x,       // X coordinate
   int         y,       // Y coordinate
   int         r,       // radius
   const uint  clr      // color
   );
```

Paraméterek

x

[in]  A kitöltött kör középpontjának X koordinátája.

y

[in]  A kitöltött kör középpontjának Y koordinátája.

r

[in]  A kitöltött kör sugara.

clr

[in]  Szín ARGB formátumban.
