# FontSizeSet


Beállítja a betűméretet.

```cpp
bool  FontSizeSet(
   int  size      // size
   );
```

Paraméterek

size

[in]  A betűméret. A méret beállításáról a [TextSetFont()](../../../../Object-Functions/TextSetFont/TextSetFont.md) függvény leírásában talál további információt.

Visszatérési érték

Siker esetén true, egyébként false.
