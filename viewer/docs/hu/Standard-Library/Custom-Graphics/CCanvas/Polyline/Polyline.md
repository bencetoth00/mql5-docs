# Polyline


Töröttvonalat rajzol.

```cpp
void  Polyline(
   int&        x[],     // array of X coordinates
   int&        y[],     // array of Y coordinates
   const uint  clr      // color
   );
```

Paraméterek

x[]

[in]  A töröttvonal X koordinátáinak tömbje.

y[]

[in]  A töröttvonal Y koordinátáinak tömbje.

clr

[in]  Szín ARGB formátumban.
