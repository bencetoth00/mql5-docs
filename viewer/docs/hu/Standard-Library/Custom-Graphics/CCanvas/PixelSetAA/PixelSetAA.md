# PixelSetAA


Élsimítási algoritmussal rajzol egy pontot.

```cpp
void  PixelSetAA(
   const double  x,       // X coordinate
   const double  y,       // Y coordinate
   const uint    clr      // color
   );
```

Paraméterek

x

[in]  A pont X koordinátája.

y

[in]  A pont Y koordinátája.

clr

[in]  Szín ARGB formátumban.
