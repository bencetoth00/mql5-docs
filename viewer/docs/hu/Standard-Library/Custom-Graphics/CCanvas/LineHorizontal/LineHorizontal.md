# LineHorizontal


Vízszintes vonalszakaszt rajzol.

```cpp
void  LineHorizontal(
   int         x1,      // X coordinate
   int         x2,      // X coordinate
   int         y,       // Y coordinate
   const uint  clr      // color
   );
```

Paraméterek

x1

[in]  A szakasz első pontjának X koordinátája.

x2

[in]  A szakasz második pontjának X koordinátája.

y

[in]  A szakasz Y koordinátája.

clr

[in]  Szín ARGB formátumban.
