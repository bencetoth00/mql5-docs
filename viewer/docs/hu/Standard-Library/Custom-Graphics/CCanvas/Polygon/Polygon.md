# Polygon


Sokszöget rajzol.

```cpp
void  Polygon(
   int&        x[],     // array of X coordinates
   int&        y[],     // array of Y coordinates
   const uint  clr      // color
   );
```

Paraméterek

x[]

[in]  A sokszög pontjainak X koordinátáit tartalmazó tömb.

y[]

[in]  A sokszög pontjainak Y koordinátáit tartalmazó tömb.

clr

[in]  Szín ARGB formátumban.
