# Fill


Kitölt egy területet.

```cpp
void  Fill(
   int         x,       // X coordinate
   int         y,       // Y coordinate
   const uint  clr      // color
   );
```

Paraméterek

x

[in]  A kitöltési terület kezdőpontjának X koordinátája.

y

[in]  A kitöltési terület kezdőpontjának Y koordinátája.

clr

[in]  Szín ARGB formátumban.
