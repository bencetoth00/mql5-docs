# CircleAA


Élsimító algoritmussal rajzol kört.

```cpp
void  CircleAA(
   const int     x,       // X coordinate
   const int     y,       // Y coordinate
   const double  r,       // radius
   const uint    clr      // color
   );
```

Paraméterek

x

[in]  A kör középpontjának X koordinátája.

y

[in]  A kör középpontjának Y koordinátája.

r

[in]  A kör sugara.

clr

[in]  Szín ARGB formátumban.
