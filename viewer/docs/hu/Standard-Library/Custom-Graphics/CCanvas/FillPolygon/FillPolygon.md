# FillPolygon


Kitöltött sokszöget rajzol.

```cpp
void  FillPolygon(
   int&         x,      // array with the X coordinates of polygon points
   int&         y,      // array with the Y coordinates of polygon points
   const uint  clr      // color
   );
```

Paraméterek

x

[in]  A sokszög csúcsai X koordinátáinak tömbje.

y

[in]  A sokszög csúcsai Y koordinátáinak tömbje.

clr

[in]  Szín ARGB formátumban.
