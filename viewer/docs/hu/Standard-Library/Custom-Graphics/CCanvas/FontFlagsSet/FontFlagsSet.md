# FontFlagsSet


Beállítja a betűtípus jelzőit.

```cpp
bool  FontFlagsSet(
   uint  flags      // flags
   );
```

Paraméterek

flags

[in]  A betűtípus létrehozásának jelzői. A jelzőkről a [TextSetFont()](../../../../Object-Functions/TextSetFont/TextSetFont.md) függvény leírásában talál további információt.

Visszatérési érték

Siker esetén true, egyébként false.
