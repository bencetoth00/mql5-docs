# PixelSet


Beállítja a pont színét a megadott koordinátákon.

```cpp
void  PixelSet(
   const int   x,       // X coordinate
   const int   y,       // Y coordinate
   const uint  clr      // color
   );
```

Paraméterek

x

[in]  A pont X koordinátája.

y

[in]  A pont Y koordinátája.

clr

[in]  Szín ARGB formátumban.
