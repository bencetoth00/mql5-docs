# TransparentLevelSet


Beállítja az átlátszóság szintjét.

```cpp
void  TransparentLevelSet(
   const uchar  value      // value
   );
```

Paraméterek

value

[in]  Az átlátszóság új szintje.

Megjegyzés

A 0 teljes átlátszóságot, a 255 teljes átlátszatlanságot jelent.

Az átlátszóság szintjének beállítása a korábban megrajzolt összes elemre hatással van. A megadott szint a későbbi rajzolásokat nem befolyásolja.
