# Checked (Get metódus)

Lekéri a vezérlő állapotát.

```cpp
bool  Checked()  const
```

Visszatérési érték

A vezérlő állapota.

 

# Checked (Set metódus)

Beállítja a vezérlő állapotát.

```cpp
bool  Checked(
   const bool  flag      // state
   )
```

Paraméterek

flag

[in]  Az új állapot.

Visszatérési érték

Siker esetén true, egyébként false.
