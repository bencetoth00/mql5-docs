# Value

# Value (Get metódus)

Lekéri a vezérlőhöz rendelt értéket.

```cpp
int  Value()  const
```

Visszatérési érték

A vezérlőhöz rendelt érték.

 

# Value (Set metódus)

Beállítja a vezérlőhöz rendelt értéket.

```cpp
void  Value(
   const int  value      // value
   )
```

Paraméterek

value

[in]  Az új érték.

Visszatérési érték

Nincs.
