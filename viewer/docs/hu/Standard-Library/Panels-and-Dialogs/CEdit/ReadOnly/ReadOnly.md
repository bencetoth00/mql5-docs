# ReadOnly

# ReadOnly (lekérő metódus)

Lekéri a vezérlő „ReadOnly” tulajdonságát.

```cpp
bool  ReadOnly()
```

Visszatérési érték

A „ReadOnly” tulajdonság értéke.

 

# ReadOnly (beállító metódus)

Beállítja a vezérlő „ReadOnly” tulajdonságát.

```cpp
bool  ReadOnly(
   const bool  flag      // value
   )
```

Paraméterek

flag

[in]  A „ReadOnly” tulajdonság új értéke.

Visszatérési érték

Siker esetén true, ellenkező esetben false.
