# OnSetFontSize


A vezérlő „SetFontSize” eseményének virtuális kezelője (az [OBJPROP\_FONTSIZE](../../../../Constants,-Enumerations-and-Structures/Objects-Constants/Object-Properties/Object-Properties.md#enum_object_property_integer) tulajdonság módosítása).

```cpp
virtual bool  OnSetFontSize()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.
