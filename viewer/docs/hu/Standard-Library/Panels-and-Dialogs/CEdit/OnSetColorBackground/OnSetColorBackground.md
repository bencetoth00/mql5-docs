# OnSetColorBackground


A vezérlő „SetColorBackground” eseményének virtuális kezelője (az [OBJPROP\_BGCOLOR](../../../../Constants,-Enumerations-and-Structures/Objects-Constants/Object-Properties/Object-Properties.md#enum_object_property_integer) tulajdonság módosítása).

```cpp
virtual bool  OnSetColorBackground()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.
