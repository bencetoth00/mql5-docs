# BmpName

# BmpName (lekérő metódus)

Lekéri a vezérlő BMP-fájljának nevét.

```cpp
string  BmpName()  const
```

Visszatérési érték

A vezérlő BMP-fájljának neve.

 

# BmpName (beállító metódus)

Beállítja a vezérlő BMP-fájljának nevét.

```cpp
bool  BmpName(
   const string  name      // file name
   )
```

Paraméterek

name

[in]  A vezérlő BMP-fájljának neve.

Visszatérési érték

Siker esetén true, ellenkező esetben false.
