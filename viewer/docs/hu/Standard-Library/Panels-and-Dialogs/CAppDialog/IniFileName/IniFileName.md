# IniFileName


Beállítja a vezérlő állapotának betöltésére/mentésére szolgáló fájl nevét.

```cpp
virtual string  IniFileName()  const
```

Visszatérési érték

A vezérlő állapotának betöltésére/mentésére szolgáló fájl neve.

Megjegyzés

A fájlnév tartalmazza annak az Expert Advisor vagy indikátornak a nevét, valamint a munkaszimbólumot, amelyen az MQL5-program fut.
