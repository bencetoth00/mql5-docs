# Destroy


A CAppDialog vezérlő inicializálásának megszüntetésére szolgáló metódus.

```cpp
virtual void  Destroy(
   const int  reason=REASON_PROGRAM    // reason code
)
```

Paraméterek

reason

[in]  Az inicializálás megszüntetésének oka. Alapértelmezés szerint [REASON\_PROGRAM](../../../../Constants,-Enumerations-and-Structures/Named-Constants/Uninitialization-Reason-Codes/Uninitialization-Reason-Codes.md).

Visszatérési érték

Nincs.
