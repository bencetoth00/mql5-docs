# Color

# Color (lekérő metódus)

Lekéri a vezérlőhöz tartozó címke színét.

```cpp
color  Color()  const
```

Visszatérési érték

A címke színe.

 

# Color (beállító metódus)

Beállítja a vezérlőhöz tartozó címke színét.

```cpp
bool  Color(
   const color  value      // color
   )
```

Paraméterek

value

[in]  Az új címkeszín.

Visszatérési érték

Siker esetén true, ellenkező esetben false.
