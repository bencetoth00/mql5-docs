# Text

# Text (Get metódus)

Lekéri a vezérlőhöz tartozó címke szövegét.

```cpp
string  Text()
```

Visszatérési érték

A címke szövege.

 

# Text (Set metódus)

Beállítja a címke szövegét.

```cpp
bool  Text(
   const string  value      // text
   )
```

Paraméterek

value

[in]  Az új szöveg.

Visszatérési érték

Siker esetén true, egyébként false.
