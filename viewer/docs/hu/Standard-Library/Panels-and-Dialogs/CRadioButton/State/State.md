# State

# State (Get metódus)

Lekéri a gomb állapotát.

```cpp
bool  State()  const
```

Visszatérési érték

A gomb állapota.

 

# State (Set metódus)

Beállítja a gomb állapotát.

```cpp
bool  State(
   const bool  flag      // flag
   )
```

Paraméterek

flag

[in]  A gomb új állapota.

Visszatérési érték

Siker esetén true, egyébként false.
