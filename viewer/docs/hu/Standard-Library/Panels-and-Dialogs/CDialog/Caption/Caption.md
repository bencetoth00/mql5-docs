# Caption (lekérő metódus)

Lekéri a CDialog vezérlő „Caption” tulajdonságát.

```cpp
string  MinValue()  const
```

Visszatérési érték

A „Caption” tulajdonság.

 

# Caption (beállító metódus)

Beállítja a CDialog vezérlő „Caption” tulajdonságát.

```cpp
bool  Caption(
   const string  text      // text
   )
```

Paraméterek

text

[in]  A „Caption” tulajdonság új értéke.

Visszatérési érték

Siker esetén true, ellenkező esetben false.
