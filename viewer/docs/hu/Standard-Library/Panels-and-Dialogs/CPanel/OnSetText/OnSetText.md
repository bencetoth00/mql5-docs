# OnSetText


A vezérlő „SetText” eseményének virtuális kezelője (az [OBJPROP\_TEXT](../../../../Constants,-Enumerations-and-Structures/Objects-Constants/Object-Properties/Object-Properties.md#enum_object_property_double) tulajdonság módosítása).

```cpp
virtual bool  OnSetText()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.
