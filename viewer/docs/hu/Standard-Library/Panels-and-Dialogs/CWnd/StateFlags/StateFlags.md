# StateFlags

# StateFlags (Get metódus)

Lekéri a vezérlő állapotjelzőit.

```cpp
int  StateFlags()
```

Visszatérési érték

A vezérlő állapotjelzői.

 

# StateFlags (Set metódus)

Beállítja a vezérlő állapotjelzőit.

```cpp
virtual void  StateFlags(
   const int  flags      // flags
   )
```

Paraméterek

flags

[in]  A vezérlő új állapotjelzői.

Visszatérési érték

Nincs.
