# Move


Abszolút módon eltolja a vezérlőt.

```cpp
void  Move(
   const int  x,     // x coordinate
   const int  y      // y coordinate
   )
```

Paraméterek

x

[in]  A bal felső pont új X koordinátája.

y

[in]  A bal felső pont új Y koordinátája.

Visszatérési érték

Siker esetén true, egyébként false.
