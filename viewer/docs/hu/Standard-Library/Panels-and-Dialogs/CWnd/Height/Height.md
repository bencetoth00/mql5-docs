# Height

# Height (Get metódus)

Lekéri a vezérlő magasságát.

```cpp
int  Height()
```

Visszatérési érték

A vezérlő magassága.

 

# Height (Set metódus)

Beállítja a vezérlő új magasságát.

```cpp
virtual bool  Height(
   const int  h      // height
   )
```

Paraméterek

h

[in]  Az új magasság.

Visszatérési érték

Siker esetén true, egyébként false.
