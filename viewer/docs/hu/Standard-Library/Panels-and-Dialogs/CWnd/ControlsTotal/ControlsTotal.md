# ControlsTotal


Lekéri a konténerben található vezérlők számát.

```cpp
int  ControlsTotal()  const
```

Visszatérési érték

A konténerben található vezérlők száma.

Megjegyzés

Az alaposztályhoz nem tartozik konténer; leszármazottai számára hozzáférést biztosít a konténerhez, és mindig 0 értéket ad vissza.
