# Width

# Width (Get metódus)

Lekéri a vezérlő szélességét.

```cpp
int  Width()
```

Visszatérési érték

A vezérlő szélessége.

 

# Width (Set metódus)

Beállítja a vezérlő szélességét.

```cpp
virtual bool  Width(
   const int  w      // width
   )
```

Paraméterek

w

[in]  Az új szélesség.

Visszatérési érték

Siker esetén true, egyébként false.
