# Align


A vezérlőt a megadott diagramterülethez igazítja.

```cpp
virtual bool  Align(
   const CRect*  rect      // pointer
   )
```

Paraméterek

rect

[in]  A diagramterület koordinátáit tartalmazó objektumra mutató pointer.

Visszatérési érték

Siker esetén true, egyébként false.

Megjegyzés

Az igazítási paramétereket meg kell adni (alapértelmezés szerint nincs igazítás).
