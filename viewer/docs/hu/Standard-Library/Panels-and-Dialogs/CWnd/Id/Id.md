# Id

# Id (Get metódus)

Lekéri a vezérlő azonosítóját.

```cpp
long  Id()  const
```

Visszatérési érték

A vezérlő azonosítója.

 

# Id (Set metódus)

Beállítja a vezérlő azonosítójának értékét.

```cpp
virtual long  Id(
   const long  id      // identifier
   )
```

Paraméterek

id

[in]  A vezérlőazonosító új értéke.

Visszatérési érték

Nincs.
