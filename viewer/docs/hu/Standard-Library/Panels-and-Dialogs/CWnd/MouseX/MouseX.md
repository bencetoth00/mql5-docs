# MouseX (Set metódus)

Elmenti az egér X koordinátáját.

```cpp
void  MouseX(
   const int  value      // coordinate
   )
```

Paraméterek

value

[in]  Az egér X koordinátája.

Visszatérési érték

Nincs.

 

# MouseX (Get metódus)

Lekéri az egér elmentett X koordinátáját.

```cpp
int  MouseX()
```

Visszatérési érték

Az egér X koordinátája.
