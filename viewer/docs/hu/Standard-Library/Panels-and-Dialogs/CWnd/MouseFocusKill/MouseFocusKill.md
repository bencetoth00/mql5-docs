# MouseFocusKill


Törli az egérgombok mentett állapotát, és deaktiválja a vezérlőt.

```cpp
bool  MouseFocusKill(
   const long  id=CONTROLS_INVALID_ID      // id
   )
```

Paraméterek

id=CONTROLS\_INVALID\_ID

[in]  Az egérfókuszt kapott vezérlő azonosítója.

Visszatérési érték

A vezérlő deaktiválásának eredménye.
