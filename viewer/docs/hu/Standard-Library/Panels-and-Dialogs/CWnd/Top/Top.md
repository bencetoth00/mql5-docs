# Top (lekérő metódus)

Lekéri a vezérlő bal felső sarkának Y koordinátáját.

```cpp
int  Top()
```

Visszatérési érték

A bal felső sarok Y koordinátája.

 

# Top (beállító metódus)

Beállítja a vezérlő bal felső sarkának Y koordinátáját.

```cpp
void  Top(
   const int  y      // y coordinate
   )
```

Paraméterek

y

[in]  A bal felső sarok új Y koordinátája.

Visszatérési érték

Nincs.
