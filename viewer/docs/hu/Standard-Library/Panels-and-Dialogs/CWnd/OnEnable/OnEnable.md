# OnEnable


A belső „Enable” esemény virtuális kezelője (engedélyezett állapotban a vezérlő reagálhat a felhasználói műveletekre).

```cpp
virtual bool  OnEnable()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
