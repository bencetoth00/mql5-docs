# Right (lekérő metódus)

Lekéri a vezérlő jobb alsó sarkának X koordinátáját.

```cpp
int  Right()
```

Visszatérési érték

A jobb alsó sarok X koordinátája.

 

# Right (beállító metódus)

Beállítja a vezérlő jobb alsó sarkának X koordinátáját.

```cpp
void  Right(
   const int  x      // x coordinate
   )
```

Paraméterek

x

[in]  A jobb alsó sarok új X koordinátája.

Visszatérési érték

Nincs.
