# OnHScrollHide


A HScroll (vízszintes görgetés) függő vezérlő „Hide” (vízszintes görgetősáv elrejtése) belső eseményének virtuális kezelője.

```cpp
virtual bool  OnHScrollHide()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
