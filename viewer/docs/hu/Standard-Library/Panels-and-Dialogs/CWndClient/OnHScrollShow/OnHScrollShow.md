# OnHScrollShow


A HScroll (vízszintes görgetés) függő vezérlő „Show” (vízszintes görgetősáv megjelenítése) belső eseményének virtuális kezelője.

```cpp
virtual bool  OnHScrollShow()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
