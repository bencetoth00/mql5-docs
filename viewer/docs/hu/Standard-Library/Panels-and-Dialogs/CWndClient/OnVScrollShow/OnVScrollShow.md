# OnVScrollShow


A VScroll (függőleges görgetés) függő vezérlő „Show” (függőleges görgetősáv megjelenítése) belső eseményének virtuális kezelője.

```cpp
virtual bool  OnVScrollShow()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
