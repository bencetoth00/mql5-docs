# OnScrollLineLeft


A HScroll (vízszintes görgetés) függő vezérlő „ScrollLineLeft” (görgetés egy sorral balra) belső eseményének virtuális kezelője.

```cpp
virtual bool  OnScrollLineLeft()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
