# OnScrollLineRight


A HScroll (vízszintes görgetés) függő vezérlő „ScrollLineRight” (görgetés egy sorral jobbra) belső eseményének virtuális kezelője.

```cpp
virtual bool  OnScrollLineRight()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
