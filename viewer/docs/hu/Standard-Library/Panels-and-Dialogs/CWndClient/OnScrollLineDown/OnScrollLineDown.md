# OnScrollLineDown


A VScroll (függőleges görgetés) függő vezérlő „ScrollLineDown” (görgetés egy sorral lefelé) belső eseményének virtuális kezelője.

```cpp
virtual bool  OnScrollLineDown()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
