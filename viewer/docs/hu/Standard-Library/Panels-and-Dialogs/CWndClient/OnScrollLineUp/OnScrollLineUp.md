# OnScrollLineUp


A VScroll (függőleges görgetés) függő vezérlő „ScrollLineUp” (görgetés egy sorral felfelé) belső eseményének virtuális kezelője.

```cpp
virtual bool  OnScrollLineUp()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
