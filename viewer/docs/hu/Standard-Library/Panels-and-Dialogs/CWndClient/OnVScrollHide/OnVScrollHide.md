# OnVScrollHide


A VScroll (függőleges görgetés) függő vezérlő „Hide” (függőleges görgetősáv elrejtése) belső eseményének virtuális kezelője.

```cpp
virtual bool  OnVScrollHide()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
