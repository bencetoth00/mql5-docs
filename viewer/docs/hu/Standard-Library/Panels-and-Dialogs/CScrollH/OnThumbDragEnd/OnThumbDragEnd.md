# OnThumbDragEnd


A vezérlő „ThumbDragEnd” (a húzás befejeződött) eseményének virtuális kezelője.

```cpp
virtual bool  OnThumbDragEnd()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

A „ThumbDragEnd” esemény akkor következik be, amikor a görgetősáv vezérlőjének (csúszkagombjának) húzása befejeződik.
