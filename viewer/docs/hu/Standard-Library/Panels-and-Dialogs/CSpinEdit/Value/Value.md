# Value (lekérő metódus)

Lekéri a vezérlő „Value” tulajdonságát (aktuális értékét).

```cpp
int  Value()  const
```

Visszatérési érték

A „Value” tulajdonság.

 

# Value (beállító metódus)

Beállítja a vezérlő „Value” tulajdonságát (aktuális értékét).

```cpp
void  Value(
   const int  value      // value
   )
```

Paraméterek

value

[in]  Az új „Value” tulajdonság.

Visszatérési érték

Nincs.
