# Contains


Ellenőrzi, hogy a pont a CRect osztály területén belül van-e.

```cpp
bool  Contains(
   const int  x,     // X coordinate
   const int  y      // Y coordinate
   )
```

Paraméterek

x

[in]  Az X koordináta.

y

[in]  Az Y koordináta.

Visszatérési érték

true, ha a pont a területen belül van (a kereteket is beleértve), egyébként false.
