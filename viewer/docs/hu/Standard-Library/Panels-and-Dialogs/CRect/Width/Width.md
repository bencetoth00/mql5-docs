# Width

# Width (Get metódus)

Lekéri a terület szélességét.

```cpp
int  Width()
```

Visszatérési érték

A terület szélessége.

 

# Width (Set metódus)

Beállítja a terület új szélességét.

```cpp
virtual bool  Width(
   const int  w      // width
   )
```

Paraméterek

w

[in]  Az új szélesség.

Visszatérési érték

Siker esetén true, egyébként false.
