# Height

# Height (Get metódus)

Lekéri a terület magasságát.

```cpp
int  Height()
```

Visszatérési érték

A terület magassága.

 

# Height (Set metódus)

Beállítja a terület új magasságát.

```cpp
virtual bool  Height(
   const int  h      // height
   )
```

Paraméterek

h

[in]  Az új magasság.

Visszatérési érték

Siker esetén true, egyébként false.
