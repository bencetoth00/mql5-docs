# OnObjectCreate


A diagramobjektum [CHARTEVENT\_OBJECT\_CREATE](../../../../Constants,-Enumerations-and-Structures/Chart-Constants/Types-of-Chart-Events/Types-of-Chart-Events.md) eseményének virtuális kezelője.

```cpp
virtual bool  OnObjectCreate()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
