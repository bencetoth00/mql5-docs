# OnSetFontSize


A „SetFontSize” esemény virtuális kezelője (az [OBJPROP\_FONTSIZE](../../../../Constants,-Enumerations-and-Structures/Objects-Constants/Object-Properties/Object-Properties.md#enum_object_property_integer) tulajdonság módosításakor).

```cpp
virtual bool  OnSetFontSize()
```

Visszatérési érték

true, ha az esemény feldolgozása megtörtént, egyébként false.

Megjegyzés

Az alaposztály metódusa nem végez műveletet, és mindig true értéket ad vissza.
