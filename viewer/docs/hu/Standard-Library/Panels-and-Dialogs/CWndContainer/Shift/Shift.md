# Shift


Relatív módon eltolja a konténer összes vezérlőjének koordinátáit.

```cpp
virtual bool  Shift(
   const int  dx,     // delta X
   const int  dy      // delta Y
   )
```

Paraméterek

dx

[in]  Az X irányú eltolás.

dy

[in]  Az Y irányú eltolás.

Visszatérési érték

Siker esetén true, egyébként false.
