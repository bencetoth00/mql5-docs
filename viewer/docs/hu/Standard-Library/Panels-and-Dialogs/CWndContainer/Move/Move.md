# Move


Abszolút módon eltolja a konténer összes vezérlőjét.

```cpp
virtual bool  Move(
   const int  x,     // X coordinate
   const int  y      // Y coordinate
   )
```

Paraméterek

x

[in]  A bal felső sarok új X koordinátája.

y

[in]  A bal felső sarok új Y koordinátája.

Visszatérési érték

Siker esetén true, egyébként false.
