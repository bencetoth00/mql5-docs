# OnMouseUp


A vezérlő „MouseUp” (bal egérgomb felengedése) eseményének virtuális kezelője.

```cpp
virtual bool  OnMouseUp()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.

Megjegyzés

A „MouseUp” esemény akkor következik be, amikor a vezérlőn felengedik a bal egérgombot.
