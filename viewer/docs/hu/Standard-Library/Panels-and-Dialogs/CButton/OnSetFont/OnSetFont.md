# OnSetFont


A vezérlő „SetFont” eseményének virtuális kezelője (az [OBJPROP\_FONT](../../../../Constants,-Enumerations-and-Structures/Objects-Constants/Object-Properties/Object-Properties.md#enum_object_property_string) tulajdonság módosítása).

```cpp
virtual bool  OnSetFont()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.
