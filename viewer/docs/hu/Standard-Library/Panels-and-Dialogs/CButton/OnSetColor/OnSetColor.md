# OnSetColor


A vezérlő „SetColor” eseményének virtuális kezelője (az [OBJPROP\_COLOR](../../../../Constants,-Enumerations-and-Structures/Objects-Constants/Object-Properties/Object-Properties.md#enum_object_property_integer) tulajdonság módosítása).

```cpp
virtual bool  OnSetColor()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.
