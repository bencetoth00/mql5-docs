# AddItem


Elemet (sort) ad hozzá a vezérlőhöz.

```cpp
bool  AddItem(
   const string  item,     // text
   const long    value     // value
   )
```

Paraméterek

item

[in]  A hozzáadott vezérlő címkeszövege.

value=0

[in]  A hozzáadott vezérlőhöz rendelt érték.

Visszatérési érték

Siker esetén true, egyébként false.
