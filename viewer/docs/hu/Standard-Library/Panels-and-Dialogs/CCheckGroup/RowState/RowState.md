# RowState


Beállítja a megadott elem állapotát.

```cpp
bool  RowState(
   const int   index,      // item index
   const bool  select      // state
   )
```

Paraméterek

index

[in]  A módosítandó elem indexe.

select

[in]  Az új állapot.

Visszatérési érték

Siker esetén true, egyébként false.
