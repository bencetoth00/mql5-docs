# TotalView


Beállítja a vezérlőn megjelenített elemek számát.

```cpp
bool  TotalView(
   const int  value      // number of items shown
   )
```

Paraméterek

value

[in]  A vezérlőn megjelenített elemek száma.

Visszatérési érték

Siker esetén true, egyébként false.

Megjegyzés

A megjelenített elemek száma csak egyszer adható meg.
