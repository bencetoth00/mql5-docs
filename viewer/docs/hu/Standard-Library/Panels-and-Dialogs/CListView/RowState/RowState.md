# RowState


Módosítja a CListView vezérlő megadott sorának állapotát.

```cpp
bool  RowState(
   const int   index      // index
   const bool  select     // state
   )
```

Paraméterek

index

[in]  A sor indexe.

select

[in]  A sor állapota.

Visszatérési érték

Siker esetén true, egyébként false.
