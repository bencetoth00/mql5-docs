# Border

# Border (lekérő metódus)

Lekéri a vezérlő „Border” (keretvastagság) tulajdonságát.

```cpp
int  Border()  const
```

Visszatérési érték

A „Border” tulajdonság.

 

# Border (beállító metódus)

Beállítja a vezérlő „Border” (keretvastagság) tulajdonságát.

```cpp
bool  Border(
   const int  value      // value
   )
```

Paraméterek

value

[in]  A „Border” tulajdonság új értéke.

Visszatérési érték

Siker esetén true, ellenkező esetben false.
