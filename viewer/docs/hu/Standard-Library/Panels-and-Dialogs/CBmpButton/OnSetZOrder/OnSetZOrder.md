# OnSetZOrder


A vezérlő „SetZOrder” eseményének virtuális kezelője (az [OBJPROP\_ZORDER](../../../../Constants,-Enumerations-and-Structures/Objects-Constants/Object-Properties/Object-Properties.md#enum_object_property_integer) tulajdonság módosítása).

```cpp
virtual bool  OnSetZOrder()
```

Visszatérési érték

true – az esemény feldolgozva, egyébként false.
