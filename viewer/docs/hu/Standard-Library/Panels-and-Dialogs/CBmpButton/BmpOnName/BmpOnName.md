# BmpOnName

# BmpOnName (lekérő metódus)

Lekéri a vezérlő BE állapotához tartozó BMP-fájl nevét.

```cpp
string  BmpOnName()  const
```

Visszatérési érték

A BE állapot BMP-fájljának neve.

 

# BmpOnName (beállító metódus)

Beállítja a vezérlő BE állapotához tartozó BMP-fájl nevét.

```cpp
bool  BmpOnName(
   const string  name      // file name
   )
```

Paraméterek

name

[in]  A BE állapot BMP-fájljának neve.

Visszatérési érték

Siker esetén true, ellenkező esetben false.
