# Locking (lekérő metódus)

Lekéri a vezérlő „Locking” tulajdonságának értékét.

```cpp
bool  Locking()  const
```

Visszatérési érték

A „Locking” tulajdonság értéke.

 

# Locking (beállító metódus)

Beállítja a vezérlő „Locking” tulajdonságának új értékét.

```cpp
void  Locking(
   const bool  locking      // value
   )
```

Paraméterek

locking

[in]  A „Locking” tulajdonság új értéke.

Visszatérési érték

Nincs.
