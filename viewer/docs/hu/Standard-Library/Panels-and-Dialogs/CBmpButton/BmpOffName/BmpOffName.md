# BmpOffName

# BmpOffName (lekérő metódus)

Lekéri a vezérlő KI állapotához tartozó BMP-fájl nevét.

```cpp
string  BmpOffName()  const
```

Visszatérési érték

A KI állapot BMP-fájljának neve.

 

# BmpOffName (beállító metódus)

Beállítja a vezérlő KI állapotához tartozó BMP-fájl nevét.

```cpp
bool  BmpOffName(
   const string  name      // file name
   )
```

Paraméterek

name

[in]  A KI állapot BMP-fájljának neve.

Visszatérési érték

Siker esetén true, ellenkező esetben false.
