# BmpNames


Beállítja a vezérlő BMP-fájljainak nevét.

```cpp
bool  BmpNames(
   const string  off="",     // file name
   const string  on=""       // file name
   )
```

Paraméterek

off=""

[in]  A BMP-fájl neve kikapcsolt állapothoz.

on=""

[in]  A BMP-fájl neve bekapcsolt állapothoz.

Visszatérési érték

Siker esetén true, egyébként false.
