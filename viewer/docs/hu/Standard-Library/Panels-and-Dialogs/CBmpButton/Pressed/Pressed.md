# Pressed (lekérő metódus)

Lekéri a vezérlő állapotát („Pressed” tulajdonságát).

```cpp
bool  Pressed()  const
```

Visszatérési érték

A vezérlő állapota.

 

# Pressed (beállító metódus)

Beállítja a vezérlő állapotát („Pressed” tulajdonságát).

```cpp
bool  Pressed(
   const bool  pressed      // state
   )
```

Paraméterek

pressed

[in]  A vezérlő új állapota.

Visszatérési érték

Siker esetén true, ellenkező esetben false.
