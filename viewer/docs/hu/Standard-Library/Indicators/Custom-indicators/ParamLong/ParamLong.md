# ParamLong


Lekéri a megadott long típusú paraméter értékét.

```cpp
long  ParamLong(
   int  index      // index
   ) const
```

Paraméterek

index

[in]  A paraméter indexe.

Visszatérési érték

A megadott long típusú paraméter értéke, amelyet az indikátor létrehozásakor használtak.

Megjegyzés

Ha a paraméter indexe érvénytelen, vagy a paraméter nem long típusú, 0 értéket ad vissza.
