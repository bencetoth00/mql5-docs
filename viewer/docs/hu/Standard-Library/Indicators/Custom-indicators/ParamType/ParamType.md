# ParamType


Lekéri a paraméter típusát.

```cpp
ENUM_DATATYPE  ParamType(
   int  index      // index
   ) const
```

Paraméterek

index

[in]  A paraméter indexe.

Visszatérési érték

A megadott paraméter adattípusa, amelyet az indikátor létrehozásakor használ.

Megjegyzés

Érvénytelen paraméterindex esetén [WRONG\_VALUE](../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md) értéket ad vissza.
