# ParamString


Lekéri a megadott string típusú paraméter értékét.

```cpp
string  ParamString(
   int  index      // index
   ) const
```

Paraméterek

index

[in]  A paraméter indexe.

Visszatérési érték

A megadott string típusú paraméter értéke, amelyet az indikátor létrehozásakor használtak.

Megjegyzés

Ha az index érvénytelen, vagy a paraméter nem string típusú, üres karakterláncot ad vissza.
