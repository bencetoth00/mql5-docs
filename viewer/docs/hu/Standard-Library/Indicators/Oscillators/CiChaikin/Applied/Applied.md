# Applied


Visszaadja az alkalmazandó adat (volumen típus) típusát.

```cpp
ENUM_APPLIED_VOLUME  Applied() const
```

Visszatérési érték

Az alkalmazandó adat (volumen típus), amelyet az indikátor létrehozásakor határoztak meg ([ENUM\_APPLIED\_VOLUME](../../../../../Constants,-Enumerations-and-Structures/Indicator-Constants/Price-Constants/Price-Constants.md) felsorolási érték).
