# PriceField


Visszaadja az alkalmazandó ármezőt (Low/High vagy Close/Close).

```cpp
ENUM_STO_PRICE  PriceField() const
```

Visszatérési érték

Az alkalmazandó ármező (Low/High vagy Close/Close), amelyet az indikátor létrehozásakor határoztak meg ([ENUM\_STO\_PRICE](../../../../../Constants,-Enumerations-and-Structures/Indicator-Constants/Price-Constants/Price-Constants.md) felsorolási érték).
