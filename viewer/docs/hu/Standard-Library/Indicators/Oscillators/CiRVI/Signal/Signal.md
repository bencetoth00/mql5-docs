# Signal


A megadott indexhez tartozó jelzővonal pufferének elemét adja vissza.

```cpp
double  Signal(
   int  index      // index
   )
```

Paraméterek

index

[in]  A puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó jelzővonal puffereleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
