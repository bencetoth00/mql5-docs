# MinIndex


Lekéri a minimális érték indexét a megadott tartományban.

```cpp
virtual int  MinIndex(
   const int  start,     // size
   const int  count      // number
   ) const
```

Paraméterek

start

[in]  A keresési tartomány kezdőindexe.

count

[in]  A keresési tartomány mérete (elemek száma).

Visszatérési érték

A sorozatpuffer minimális értékének indexe a megadott tartományban, vagy -1.
