# MaxIndex


Lekéri a legnagyobb érték indexét a megadott tartományban.

```cpp
virtual int  MaxIndex(
   const int  start,     // index
   const int  count      // number
   ) const
```

Paraméterek

start

[in]  A keresési tartomány kezdőindexe.

count

[in]  A keresési tartomány mérete (az elemek száma).

Visszatérési érték

A sorozatpuffer legnagyobb értékének indexe a megadott tartományban, vagy -1.
