# GetData


Lekéri a megadott idősor-pufferelemet.

```cpp
double  GetData(
   const int  index      // index
   ) const
```

Paraméterek

index

[in]  A pufferelem indexe.

Visszatérési érték

Az idősor puffereleme vagy az [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md).
