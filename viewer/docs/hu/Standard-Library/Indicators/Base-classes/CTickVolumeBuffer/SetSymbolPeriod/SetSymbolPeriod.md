# SetSymbolPeriod


Beállítja a szimbólumot és az idősíkot.

```cpp
void  SetSymbolPeriod(
   const string           symbol,     // symbol
   const ENUM_TIMEFRAMES  period      // period
   )
```

Paraméterek

symbol

[in]  Az új szimbólum.

period

[in]  Az új idősík ([ENUM\_TIMEFRAMES](../../../../../Constants,-Enumerations-and-Structures/Chart-Constants/Chart-Timeframes/Chart-Timeframes.md) felsorolás).
