# Refresh


Frissíti a teljes puffert.

```cpp
bool  Refresh(
   const int  handle,     // indicator handle
   const int  num         // buffer number
   )
```

Paraméterek

handle

[in]  Az indikátor kezelője.

num

[in]  Az indikátor pufferének indexe.

Visszatérési érték

Siker esetén true, ha a puffer nem frissíthető, false.
