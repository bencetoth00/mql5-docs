# AddToChart


Hozzáadja az indikátort a diagramhoz.

```cpp
bool  AddToChart(
   const long  chart,     // chart ID
   const int  subwin      // subwindow index
   )
```

Paraméterek

chart

[in]  A diagram azonosítója.

subwin

[in]  A diagram alablakának indexe.

Visszatérési érték

Siker esetén true, ha az indikátor nem adható hozzá a diagramhoz, false.
