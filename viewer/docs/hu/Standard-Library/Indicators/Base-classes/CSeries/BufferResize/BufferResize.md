# BufferResize


Beállítja az idősor vagy indikátor pufferének méretét.

```cpp
virtual bool  BufferResize(
   const int  size      // size
   )
```

Paraméterek

size

[in]  A pufferek új mérete.

Visszatérési érték

Siker esetén true, egyébként false.

Megjegyzés

Az idősor vagy indikátor összes puffere azonos méretű.
