# Main


Visszaadja a pufferelemet a megadott indexen.

```cpp
double  Main(
   int  index      // index
   )
```

Paraméterek

index

[in]  A pufferelem indexe.

Visszatérési érték

Siker esetén a megadott indexű pufferelem, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
