# Base


A megadott indexhez tartozó középvonal pufferének elemét adja vissza.

```cpp
double  Base(
   int  index      // index
   )
```

Paraméterek

index

[in]  A középvonal puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó középvonal puffereleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
