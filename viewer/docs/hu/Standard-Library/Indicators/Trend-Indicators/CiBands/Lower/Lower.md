# Lower


A megadott indexhez tartozó alsó vonal pufferének elemét adja vissza.

```cpp
double  Lower(
   int  index      // index
   )
```

Paraméterek

index

[in]  Az alsó vonal puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó alsó vonal puffereleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
