# Upper


A megadott indexhez tartozó felső vonal pufferének elemét adja vissza.

```cpp
double  Upper(
   int  index      // index
   )
```

Paraméterek

index

[in]  A felső vonal puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó felső vonal puffereleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
