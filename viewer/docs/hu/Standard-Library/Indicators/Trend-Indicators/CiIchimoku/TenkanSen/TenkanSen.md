# TenkanSen


A megadott indexhez tartozó TenkanSen vonal pufferének elemét adja vissza.

```cpp
double  TenkanSen(
   int  index      // index
   )
```

Paraméterek

index

[in]  A TenkanSen vonal puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó TenkanSen vonal puffereleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
