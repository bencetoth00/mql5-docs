# KijunSen


A megadott indexhez tartozó KijunSen vonal pufferének elemét adja vissza.

```cpp
double  KijunSen(
   int  index      // index
   )
```

Paraméterek

index

[in]  A KijunSen vonal puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó KijunSen vonal puffereleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
