# Plus


A megadott indexhez tartozó +DI vonal pufferének elemét adja vissza.

```cpp
double  Plus(
   int  index      // index
   )
```

Paraméterek

index

[in]  A +DI vonal puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó +DI vonal puffereleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
