# Main


A megadott indexhez tartozó fő vonal pufferének elemét adja vissza.

```cpp
double  Main(
   int  index      // index
   )
```

Paraméterek

index

[in]  A fő vonal puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó fő vonal pufferének eleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
