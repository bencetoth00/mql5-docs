# Applied


Visszaadja az alkalmazandó volumen típusát.

```cpp
ENUM_APPLIED_VOLUME  Applied() const
```

Visszatérési érték

Az alkalmazandó volumen típusa, amelyet az indikátor létrehozásakor határoztak meg ([ENUM\_APPLIED\_VOLUME](../../../../../Constants,-Enumerations-and-Structures/Indicator-Constants/Price-Constants/Price-Constants.md) felsorolási érték).
