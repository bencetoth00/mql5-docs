# Lips


A megadott indexhez tartozó Lips vonal pufferének elemét adja vissza.

```cpp
double  Lips(
   int  index      // index
   )
```

Paraméterek

index

[in] A Lips vonal puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó Lips vonal puffereleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
