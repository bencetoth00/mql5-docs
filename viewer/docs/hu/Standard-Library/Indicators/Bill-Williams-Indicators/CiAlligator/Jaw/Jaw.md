# Jaw


A megadott indexhez tartozó Jaws vonal pufferének elemét adja vissza.

```cpp
double  Jaw(
   int  index      // index
   )
```

Paraméterek

index

[in]  A Jaws vonal puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó Jaws vonal puffereleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
