# Teeth


A megadott indexhez tartozó Teeth vonal pufferének elemét adja vissza.

```cpp
double  Teeth(
   int  index      // index
   )
```

Paraméterek

index

[in]  A Teeth vonal puffer elemének indexe.

Visszatérési érték

A megadott indexhez tartozó Teeth vonal puffereleme, vagy [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md), ha nincs érvényes adat.
