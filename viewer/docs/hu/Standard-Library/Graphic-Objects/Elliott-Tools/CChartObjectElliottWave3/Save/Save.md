# Save


Fájlba menti az objektum paramétereit.

```cpp
virtual bool  Save(
   int  file_handle      // file handle
   )
```

Paraméterek

file\_handle

[in]  A [FileOpen(...) ](../../../../Files/FileOpen.md) függvénnyel korábban megnyitott bináris fájl kezelője.

Visszatérési érték

Siker esetén true, hiba esetén false.
