# Load


Betölti az objektum paramétereit fájlból.

```cpp
virtual bool  Load(
   int  file_handle      // file handle
   )
```

Paraméterek

file\_handle

[in]  A [FileOpen(...) ](../../../../Files/FileOpen.md) függvénnyel korábban megnyitott fájl kezelője.

Visszatérési érték

Siker esetén true, hiba esetén false.
