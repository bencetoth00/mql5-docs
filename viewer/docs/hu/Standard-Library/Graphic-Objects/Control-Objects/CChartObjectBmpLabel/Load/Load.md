# Load


Betölti az objektum paramétereit fájlból.

```cpp
virtual bool  Load(
   int  file_handle      // file handle
   )
```

Paraméterek

file\_handle

[in]  A [FileOpen](../../../../../File-Functions/FileOpen/FileOpen.md) függvénnyel korábban megnyitott bináris fájl kezelője.

Visszatérési érték

Siker esetén true, hiba esetén false.
