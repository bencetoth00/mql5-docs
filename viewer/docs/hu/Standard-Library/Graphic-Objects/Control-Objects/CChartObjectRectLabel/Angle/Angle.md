# Angle


Megakadályozza a dőlésszög tulajdonság módosítását.

```cpp
bool  Angle(
   double  angle      // any value
   )
```

Paraméterek

angle

[in]  Bármilyen [double](../../../../../Language-Basics/Data-Types/Real-Types-(double,-float)/Real-Types-(double,-float).md) típusú érték.

Visszatérési érték

Mindig false.
