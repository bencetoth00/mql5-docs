# ReadObject


Beolvassa a CObject osztályból származó példány adatait a fájlból.

```cpp
bool  ReadObject(
   CObject*  object      // pointer
   )
```

Paraméterek

object

[in]  A CObject osztályból származó beolvasandó példányra mutató pointer.

Visszatérési érték

Siker esetén true, ha az adat nem olvasható be, false.
