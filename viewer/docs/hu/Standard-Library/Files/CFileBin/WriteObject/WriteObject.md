# WriteObject


Fájlba írja a CObject osztályból származó példány adatait.

```cpp
bool  WriteObject(
   CObject*  object      // reference to the object
   )
```

Paraméterek

object

[in]  A fájlba írandó, CObject osztályból származó példány referenciája.

Visszatérési érték

Siker esetén true, ha az adatok nem írhatók fájlba, false.
