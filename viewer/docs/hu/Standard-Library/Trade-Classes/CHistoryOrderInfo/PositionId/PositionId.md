# PositionId


Lekéri a pozíció azonosítóját.

```cpp
long  PositionId() const
```

Visszatérési érték

Annak a pozíciónak az azonosítója, amelyben a megbízás részt vett.

Megjegyzés

A múltbeli megbízást a [Ticket](../Ticket/Ticket.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
