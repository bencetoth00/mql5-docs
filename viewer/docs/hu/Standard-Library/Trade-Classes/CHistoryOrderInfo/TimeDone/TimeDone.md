# TimeDone


Lekéri a megbízás végrehajtásának vagy törlésének időpontját.

```cpp
datetime  TimeDone() const
```

Visszatérési érték

A megbízás végrehajtásának vagy törlésének időpontja.

Megjegyzés

A múltbeli megbízást a [Ticket](../Ticket/Ticket.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
