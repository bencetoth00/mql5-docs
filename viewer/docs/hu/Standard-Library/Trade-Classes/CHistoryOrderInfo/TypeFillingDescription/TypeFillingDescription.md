# TypeFillingDescription


Szövegesen lekéri a megbízás részleges végrehajtási típusát.

```cpp
string  TypeFillingDescription() const
```

Visszatérési érték

A megbízás részleges végrehajtási típusa szövegesen.

Megjegyzés
