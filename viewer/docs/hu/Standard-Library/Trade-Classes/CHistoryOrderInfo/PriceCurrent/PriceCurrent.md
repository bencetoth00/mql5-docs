# PriceCurrent


Lekéri a megbízás szimbólumának aktuális árát.

```cpp
double  PriceCurrent() const
```

Visszatérési érték

A megbízás szimbólumának aktuális ára.

Megjegyzés

A múltbeli megbízást a [Ticket](../Ticket/Ticket.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
