# TypeTimeDescription


Szövegesen lekéri a megbízás lejárati idő szerinti típusát.

```cpp
string  TypeTimeDescription() const
```

Visszatérési érték

A megbízás lejárati idő szerinti típusa szövegesen.

Megjegyzés

A múltbeli megbízást a [Ticket](../Ticket/Ticket.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
