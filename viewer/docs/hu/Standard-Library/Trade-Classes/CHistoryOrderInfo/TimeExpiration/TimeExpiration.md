# TimeExpiration


Lekéri a megbízás lejárati idejét.

```cpp
datetime  TimeExpiration() const
```

Visszatérési érték

A megbízás elhelyezésekor beállított lejárati idő.

Megjegyzés

A múltbeli megbízást a [Ticket](../Ticket/Ticket.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
