# State


Lekéri a megbízás állapotát.

```cpp
ENUM_ORDER_STATE  State() const
```

Visszatérési érték

A megbízás állapota az [ENUM\_ORDER\_STATE](../../../../Constants,-Enumerations-and-Structures/Trade-Constants/Order-Properties/Order-Properties.md#enum_order_state) felsorolásból.

Megjegyzés

A korábbi megbízást a [Ticket](../Ticket/Ticket.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
