# Path


Lekéri az ügyfélterminál mappájának elérési útját.

```cpp
string  Path() const
```

Visszatérési érték

Az ügyfélterminál mappájának elérési útja.

Megjegyzés

Az ügyfélterminál mappájának elérési útját a [TerminalInfoString()](../../../../Checkup/TerminalInfoString/TerminalInfoString.md) függvény [TERMINAL\_PATH](../../../../Constants,-Enumerations-and-Structures/Environment-State/Client-Terminal-Properties/Client-Terminal-Properties.md#enum_terminal_info_integer) tulajdonsága használja.
