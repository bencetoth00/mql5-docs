# TimeUpdate


Lekéri a pozíció módosításának időpontját másodpercben 1970.01.01. óta.

```cpp
datetime  TimeUpdate() const
```

Visszatérési érték

A pozíció módosításának időpontja másodpercben 1970.01.01. óta.

Megjegyzés

Az adatok eléréséhez előzetesen ki kell választani a pozíciót a [Select](../Select/Select.md) (szimbólum alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal.
