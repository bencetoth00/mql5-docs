# Commission


Lekéri a pozíció jutalékának összegét.

```cpp
double  Commission() const
```

Visszatérési érték

A pozíció jutaléka (a számla pénznemében).

Megjegyzés

A pozíciót a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
