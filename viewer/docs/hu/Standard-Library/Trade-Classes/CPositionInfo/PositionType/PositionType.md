# PositionType


Lekéri a pozíció típusát.

```cpp
ENUM_POSITION_TYPE  PositionType() const
```

Visszatérési érték

A pozíció típusa az [ENUM\_POSITION\_TYPE](../../../../Constants,-Enumerations-and-Structures/Trade-Constants/Position-Properties/Position-Properties.md#enum_position_type) felsorolásból.

Megjegyzés

A pozíciót a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
