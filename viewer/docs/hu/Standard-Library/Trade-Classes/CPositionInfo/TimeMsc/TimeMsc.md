# TimeMsc


Lekéri a pozíció nyitásának időpontját ezredmásodpercben 1970.01.01. óta.

```cpp
ulong  TimeMsc() const
```

Visszatérési érték

A pozíció nyitásának időpontja ezredmásodpercben 1970.01.01. óta.

Megjegyzés

Az adatok eléréséhez előzetesen ki kell választani a pozíciót a [Select](../Select/Select.md) (szimbólum alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal.
