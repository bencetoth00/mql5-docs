# PriceCurrent


Lekéri az aktuális árat a pozíció szimbólumához.

```cpp
double  PriceCurrent() const
```

Visszatérési érték

Az aktuális ár a pozíció szimbólumához.

Megjegyzés

A pozíciót a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
