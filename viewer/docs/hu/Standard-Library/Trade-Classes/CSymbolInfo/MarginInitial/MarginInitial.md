# MarginInitial


Lekéri a kezdeti margin értékét.

```cpp
double  MarginInitial()
```

Visszatérési érték

A kezdeti margin értéke.

Megjegyzés

Visszaadja az egy lotra felszámított margin összegét az instrumentum margin-pénznemében. A piaci belépéskor az ügyfél saját tőkéjének ellenőrzésére használatos.

A szimbólumot a [Name](../Name/Name.md) metódussal kell kiválasztani.
