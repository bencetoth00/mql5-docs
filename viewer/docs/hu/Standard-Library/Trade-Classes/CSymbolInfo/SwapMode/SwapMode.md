# SwapMode


Lekéri a swap számítási módját.

```cpp
ENUM_SYMBOL_SWAP_MODE  SwapMode() const
```

Visszatérési érték

A swap számítási módja az [ENUM\_SYMBOL\_SWAP\_MODE](../../../../Constants,-Enumerations-and-Structures/Environment-State/Symbol-Properties/Symbol-Properties.md#enum_symbol_swap_mode) felsorolásból.

Megjegyzés

A szimbólumot a [Name](../Name/Name.md) metódussal kell kiválasztani.
