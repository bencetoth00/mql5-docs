# LotsLimit


Lekéri egy szimbólumra a nyitott pozíciók és függő megbízások megengedett legnagyobb volumenét, iránytól függetlenül.

```cpp
double  LotsLimit() const
```

Visszatérési érték

Egy szimbólumra a nyitott pozíciók és függő megbízások megengedett legnagyobb volumene, iránytól függetlenül.

Megjegyzés

A szimbólumot a [Name](../Name/Name.md) metódussal kell kiválasztani.
