# NormalizePrice


Visszaadja a szimbólum tulajdonságai szerint normalizált árat.

```cpp
double  NormalizePrice(
   double  price   // price
   ) const
```

Paraméterek

price

[in]  Az ár.

Visszatérési érték

A normalizált ár.

Megjegyzés

A szimbólumot a [Name](../Name/Name.md) metódussal kell kiválasztani.
