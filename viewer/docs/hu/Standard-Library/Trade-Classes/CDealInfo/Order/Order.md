# Order


Lekéri azt a megbízást, amely alapján az ügylet végrehajtásra került.

```cpp
long  Order() const
```

Visszatérési érték

Az ügylet végrehajtásának alapjául szolgáló megbízás.

Megjegyzés

Az ügyletet a [Ticket](../Ticket/Ticket.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
