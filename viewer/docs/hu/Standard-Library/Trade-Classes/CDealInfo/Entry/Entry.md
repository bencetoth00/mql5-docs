# Entry


Összehasonlítja az ügylet irányát.

```cpp
ENUM_DEAL_ENTRY  Entry() const
```

Visszatérési érték

Az ügylet iránya (az [ENUM\_DEAL\_ENTRY](../../../../Constants,-Enumerations-and-Structures/Trade-Constants/Deal-Properties/Deal-Properties.md#enum_deal_entry) felsorolás értéke).

Megjegyzés

Az ügyletet a [Ticket](../Ticket/Ticket.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
