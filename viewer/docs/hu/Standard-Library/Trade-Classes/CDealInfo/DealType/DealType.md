# DealType


Lekéri az ügylet típusát.

```cpp
ENUM_DEAL_TYPE  DealType() const
```

Visszatérési érték

Az ügylet típusa az [ENUM\_DEAL\_TYPE](../../../../Constants,-Enumerations-and-Structures/Trade-Constants/Deal-Properties/Deal-Properties.md#enum_deal_type) felsorolásból.

Megjegyzés

Az ügyletet a [Ticket](../Ticket/Ticket.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
