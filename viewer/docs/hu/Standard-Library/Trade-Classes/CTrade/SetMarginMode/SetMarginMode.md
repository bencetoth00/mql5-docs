# SetMarginMode


Az aktuális számlabeállításoknak megfelelően állítja be a margin számítási módját.

```cpp
void  SetMarginMode()
```

Visszatérési érték

Nincs.

Megjegyzés

A margin számítási módját az [ENUM\_ACCOUNT\_MARGIN\_MODE](../../../../Constants,-Enumerations-and-Structures/Environment-State/Account-Properties/Account-Properties.md#enum_account_info_integer) határozza meg.
