# TimeDone


Lekéri a megbízás végrehajtásának vagy törlésének időpontját.

```cpp
datetime  TimeDone() const
```

Visszatérési érték

A megbízás végrehajtásának vagy törlésének időpontja.

Megjegyzés

A megbízást a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
