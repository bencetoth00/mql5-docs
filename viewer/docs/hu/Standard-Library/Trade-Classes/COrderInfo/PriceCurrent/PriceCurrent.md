# PriceCurrent


Lekéri az aktuális árat a megbízás szimbólumához.

```cpp
double  PriceCurrent() const
```

Visszatérési érték

Az aktuális ár a megbízás szimbólumához.

Megjegyzés

A megbízást a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
