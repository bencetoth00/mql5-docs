# VolumeCurrent


Lekéri a megbízás még nem teljesült volumenét.

```cpp
double  VolumeCurrent() const
```

Visszatérési érték

A megbízás még nem teljesült volumene.

Megjegyzés

A megbízást a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
