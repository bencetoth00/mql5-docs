# TimeDoneMsc


Lekéri a megbízás végrehajtásának vagy törlésének idejét az 1970.01.01. óta eltelt ezredmásodpercekben.

```cpp
ulong  TimeDoneMsc() const
```

Visszatérési érték

A megbízás végrehajtásának vagy törlésének ideje az 1970.01.01. óta eltelt ezredmásodpercekben.

Megjegyzés

A metódus használata előtt a megbízást ki kell választani a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal.
