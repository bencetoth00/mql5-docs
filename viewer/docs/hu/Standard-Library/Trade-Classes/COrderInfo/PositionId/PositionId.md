# PositionId


Lekéri a pozíció azonosítóját.

```cpp
long  PositionId() const
```

Visszatérési érték

Annak a pozíciónak az azonosítója, amelyben a megbízás részt vett.

Megjegyzés

A megbízást a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
