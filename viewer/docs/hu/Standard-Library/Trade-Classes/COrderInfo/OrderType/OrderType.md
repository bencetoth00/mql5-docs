# OrderType


Lekéri a megbízás típusát.

```cpp
ENUM_ORDER_TYPE  OrderType()
```

Visszatérési érték

A megbízás típusa az [ENUM\_ORDER\_TYPE](../../../../Constants,-Enumerations-and-Structures/Trade-Constants/Order-Properties/Order-Properties.md#enum_order_type) felsorolásból.

Megjegyzés

A megbízást a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
