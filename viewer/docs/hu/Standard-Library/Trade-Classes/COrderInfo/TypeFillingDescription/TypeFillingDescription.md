# TypeFillingDescription


Szövegesen lekéri a megbízás végrehajtási típusát.

```cpp
string  TypeFillingDescription() const
```

Visszatérési érték

A megbízás végrehajtási típusa szövegesen.

Megjegyzés

A megbízást a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
