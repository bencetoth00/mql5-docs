# TimeExpiration


Lekéri a megbízás lejárati idejét.

```cpp
datetime  TimeExpiration() const
```

Visszatérési érték

A megbízás elhelyezésekor beállított lejárati idő.

Megjegyzés

A megbízást a [Select](../Select/Select.md) (jegy alapján) vagy a [SelectByIndex](../SelectByIndex/SelectByIndex.md) (index alapján) metódussal kell kiválasztani.
