# HeightInPixels


Lekéri az ablak magasságát pixelben.

```cpp
int  HeightInPixels(
   int  num      // subwindow
   ) const
```

Paraméterek

num

[in]  A vizsgált alablak sorszáma (0 a főablakot jelöli).

Visszatérési érték

Az osztálypéldányhoz rendelt diagram ablakának magassága pixelben. Ha nincs diagram rendelve, 0 értéket ad vissza.
