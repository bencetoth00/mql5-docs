# PriceMin


Lekéri az ablak legalacsonyabb árát.

```cpp
double  PriceMin(
   int  num      // subwindow
   ) const
```

Paraméterek

num

[in]  Az alablak száma (a 0 a főablakot jelenti).

Visszatérési érték

Az osztálypéldányhoz rendelt diagramablak legalacsonyabb ára. Ha nincs hozzárendelt diagram, [EMPTY\_VALUE](../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md) értéket ad vissza.
