# WindowIsVisible


Lekéri a megadott diagram-aldoblak láthatósági jelzőjét.

```cpp
bool  WindowIsVisible(
   int  num      // subwindow
   ) const
```

Paraméterek

num

[in]  Az alablak sorszáma (0 a főablakot jelöli).

Visszatérési érték

Az osztálypéldányhoz rendelt diagram megadott alablakának láthatósági jelzője. Ha nincs diagram rendelve, false értéket ad vissza.
