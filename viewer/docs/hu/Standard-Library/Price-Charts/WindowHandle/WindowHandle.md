# WindowHandle


Lekéri a diagram ablakkezelőjét (HWND).

```cpp
int  WindowHandle() const
```

Visszatérési érték

A diagram példányhoz rendelt diagram ablakkezelője. Ha nincs diagram hozzárendelve, az [INVALID\_HANDLE](../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md) értéket adja vissza.
