# DecreaseFactor


Beállítja a csökkentési tényező értékét.

```cpp
void  DecreaseFactor(
   double  decrease_factor      // decrease factor
   )
```

Paraméterek

decrease\_factor

[in]  A csökkentési tényező.

Megjegyzés

A DecreaseFactor a nyitott pozíció volumenének csökkentési együtthatóját határozza meg az előző pozíció volumenéhez képest, egymást követő veszteséges ügyletek esetén.
