# InitIndicators


Inicializálja az indikátorokat és az idősorokat.

```cpp
virtual bool  InitIndicators(
   CIndicators*  indicators      // pointer
   )
```

Paraméterek

indicators

[in]  Pointer az indikátorok és idősorok gyűjteményére (a [CExpert](../../../Base-classes-for-Expert-Advisors/CExpert/CExpert.md) osztálytagja).

Visszatérési érték

Siker esetén true, egyébként false.
