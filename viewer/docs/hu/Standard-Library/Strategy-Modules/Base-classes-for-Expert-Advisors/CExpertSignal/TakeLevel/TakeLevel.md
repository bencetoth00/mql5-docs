# TakeLevel


Beállítja a „TakeLevel” paraméter új értékét.

```cpp
void  TakeLevel(
   double    value         // value
   )
```

Paraméterek

value

[in]  A „TakeLevel” új értéke.

Visszatérési érték

Nincs.

Megjegyzés

A „TakeLevel” értéke árskálaegységben van megadva. Az árskálaegység numerikus értékét a PriceLevelUnit() metódus adja vissza. A „TakeLevel” a nyitóárhoz viszonyított Take Profit ár meghatározására szolgál.
