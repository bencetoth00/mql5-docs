# CloseShortParams


Beállítja a rövid pozíció lezárásához szükséges paramétereket.

```cpp
virtual bool  CloseShortParams(
   double&    price          // price
   )
```

Paraméterek

price

[in][out]  Referencia szerint átadott változó a záróárhoz.

Visszatérési érték

Siker esetén true, egyébként false.
