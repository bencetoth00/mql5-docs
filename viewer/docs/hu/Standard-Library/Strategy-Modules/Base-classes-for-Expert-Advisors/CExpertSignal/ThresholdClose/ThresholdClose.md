# ThresholdClose


Beállítja a „ThresholdClose” paraméter új értékét.

```cpp
void  ThresholdOpen(
   long    value         // value
   )
```

Paraméterek

value

[in]  A „ThresholdClose” új értéke.

Visszatérési érték

Nincs.

Megjegyzés

A „ThresholdClose” paraméter értéktartománya 0 és 100 között van. Pozíció zárásakor történő „szavazásnál” használatos.
