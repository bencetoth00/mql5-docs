# PriceLevel


Beállítja a „PriceLevel” paraméter új értékét.

```cpp
void  PriceLevel(
   double    value         // value
   )
```

Paraméterek

value

[in]  A „PriceLevel” új értéke.

Visszatérési érték

Nincs.

Megjegyzés

A „PriceLevel” értéke árskálaegységben van megadva. Az árskálaegység numerikus értékét a PriceLevelUnit() metódus adja vissza. A „PriceLevel” a bázisárhoz viszonyított nyitóár meghatározására szolgál.
