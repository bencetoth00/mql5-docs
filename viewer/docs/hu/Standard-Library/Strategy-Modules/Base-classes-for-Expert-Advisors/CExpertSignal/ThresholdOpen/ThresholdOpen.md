# ThresholdOpen


Beállítja a „ThresholdOpen” paraméter új értékét.

```cpp
void  ThresholdOpen(
   long    value         // value
   )
```

Paraméterek

value

[in]  A „ThresholdOpen” új értéke.

Visszatérési érték

Nincs.

Megjegyzés

A „ThresholdOpen” paraméter értéktartománya 0 és 100 között van. Pozíció nyitásakor történő „szavazásnál” használatos.
