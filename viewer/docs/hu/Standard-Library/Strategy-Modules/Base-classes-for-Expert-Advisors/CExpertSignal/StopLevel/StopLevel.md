# StopLevel


Beállítja a „StopLevel” paraméter új értékét.

```cpp
void  StopLevel(
   double    value         // value
   )
```

Paraméterek

value

[in]  A „StopLevel” új értéke.

Visszatérési érték

Nincs.

Megjegyzés

A „StopLevel” értéke árskálaegységben van megadva. Az árskálaegység numerikus értékét a PriceLevelUnit() metódus adja vissza. A „StopLevel” a nyitóárhoz viszonyított Stop Loss ár meghatározására szolgál.
