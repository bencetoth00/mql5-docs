# Direction


Visszaadja a „súlyozott” árirány értékét.

```cpp
virtual double  Direction()
```

Visszatérési érték

Pozitív értéket ad vissza, ha a felfelé irányuló mozgás a valószínűbb, negatív értéket pedig lefelé irányuló mozgás esetén. Az abszolút érték a jelzés „erősségétől” függ.

Megjegyzés

Beépített szűrők használatakor azok eredményeit is figyelembe veszi az általános irány meghatározásakor.
