# CloseLongParams


Beállítja a hosszú pozíció lezárásához szükséges paramétereket.

```cpp
virtual bool  CloseLongParams(
   double&    price          // price
   )
```

Paraméterek

price

[in][out]  Referencia szerint átadott változó a záróárhoz.

Visszatérési érték

Siker esetén true, egyébként false.
