# Expiration


Beállítja az „Expiration” paraméter értékét.

```cpp
void  Expiration(
   int    value         // value
   )
```

Paraméterek

value

[in]  Az „Expiration” új értéke.

Visszatérési érték

Nincs.

Megjegyzés

Az „Expiration” paraméter értéke gyertyákban van megadva. Függő megbízással történő kereskedéskor a megbízás lejárati idejeként használatos.
