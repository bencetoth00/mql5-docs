# TimeframesFlags


Létrehozza az idősíkjelzőket.

```cpp
int  TimeframesFlags(
   MqlDateTime&    time         // reference
   )
```

Paraméterek

time

[in]  Új időt tartalmazó [MqlDateTime](../../../../../Constants,-Enumerations-and-Structures/Data-Structures/Date-Type-Structure/Date-Type-Structure.md) típusú struktúrára mutató hivatkozás.

Visszatérési érték

Azt a jelzőt adja vissza, amely az új gyertyával rendelkező idősíkokat jelzi.
