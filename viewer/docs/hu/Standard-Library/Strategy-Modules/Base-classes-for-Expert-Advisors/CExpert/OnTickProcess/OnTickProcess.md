# OnTickProcess


Beállítja az [OnTick](../../../../../Event-Handling/OnTick/OnTick.md) eseménykezelési jelzőjét.

```cpp
void  OnTickOProcess(
   bool     value        // flag
   )
```

Paraméterek

value

[in] Az [OnTick](../../../../../Event-Handling/OnTick/OnTick.md) esemény kezelési jelzője.

Visszatérési érték

Nincs.

Megjegyzés

Ha a jelző true, az [OnTick](../../../../../Event-Handling/OnTick/OnTick.md) esemény kezelése megtörténik. Alapértelmezés szerint a jelző értéke true.
