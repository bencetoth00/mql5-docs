# CheckOpenShort


Lekéri a rövid pozíció volumenét.

```cpp
virtual double  CheckOpenShort(
   double  price,     // price
   double  sl         // Stop Loss
   )
```

Paraméterek

price

[in]  A rövid pozíció nyitási ára.

sl

[in]  A rövid pozíció Stop Loss ára.

Visszatérési érték

A rövid pozíció kereskedési volumene.
