# CheckOpenLong


Lekéri a hosszú pozíció volumenét.

```cpp
virtual double  CheckOpenLong(
   double  price,     // price
   double  sl         // Stop Loss
   )
```

Paraméterek

price

[in]  A hosszú pozíció nyitási ára.

sl

[in]  A hosszú pozíció Stop Loss ára.

Visszatérési érték

A hosszú pozíció kereskedési volumene.
