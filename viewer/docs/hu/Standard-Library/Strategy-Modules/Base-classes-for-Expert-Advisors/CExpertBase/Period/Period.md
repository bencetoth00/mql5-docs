# Period


Beállítja az objektum idősíkját.

```cpp
bool  Period(
   ENUM_TIMEFRAMES  value     // timeframe
   )
```

Paraméterek

value

[in]  Az idősík.

Visszatérési érték

Siker esetén true, egyébként false.

Megjegyzés

A munkaszimbólum beállítása akkor szükséges, ha az objektum az inicializáláskor megadottól eltérő idősíkot használ.
