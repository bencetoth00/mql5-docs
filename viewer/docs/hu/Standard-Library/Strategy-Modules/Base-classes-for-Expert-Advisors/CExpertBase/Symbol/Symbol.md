# Symbol


Beállítja az objektum szimbólumát.

```cpp
bool  Symbol(
   string    name     // symbol
   )
```

Paraméterek

name

[in]  A szimbólum.

Visszatérési érték

Siker esetén true, egyébként false.

Megjegyzés

A munkaszimbólum beállítása akkor szükséges, ha az objektum az első inicializáláskor megadottól eltérő szimbólumot használ.
