# CompareMagic


Összehasonlítja az Expert Advisor azonosítóját (magic) a megadott értékkel.

```cpp
virtual bool  CompareMagic(
   ulong  magic    // identifier
   )
```

Paraméterek

magic

[in]  Az összehasonlítandó azonosítóérték.

Visszatérési érték

true, ha az azonosító megegyezik a megadott értékkel, egyébként false.
