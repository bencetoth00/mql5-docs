# TrimRight


Eltávolítja a karakterlánc végéről a megadott halmazban található karaktereket, valamint a szóközt, tabulátort, kocsi vissza karaktert és soremelést.

```cpp
int  TrimRight(
   const string  targets      // set
   )
```

Paraméterek

targets

[in]  Az eltávolítandó karakterek halmaza.

Visszatérési érték

Az eltávolított karakterek száma.
