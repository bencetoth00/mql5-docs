# TrimLeft


Eltávolítja a karakterlánc elejéről a megadott halmazban található karaktereket, valamint a szóközt, tabulátort, kocsi vissza karaktert és soremelést.

```cpp
int  TrimLeft(
   const string  targets      // set
   )
```

Paraméterek

targets

[in]  Az eltávolítandó karakterek halmaza.

Visszatérési érték

Az eltávolított karakterek száma.
