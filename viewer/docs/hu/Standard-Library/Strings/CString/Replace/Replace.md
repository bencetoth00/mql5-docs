# Replace


Lecseréli az összes egyező részkarakterláncot.

```cpp
uint  Replace(
   const string  substring,     // substring
   const string  newstring      // substring
   )
```

Paraméterek

substring

[in]  A keresendő részkarakterlánc.

newstring

[in]  A behelyettesítendő részkarakterlánc.

Visszatérési érték

A részkarakterlánc-cserék száma.
