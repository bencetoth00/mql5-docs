# FindRev


Megkeresi egy részkarakterlánc utolsó előfordulását.

```cpp
int  FindRev(
   const string  substring      // substring
   ) const;
```

Paraméterek

substring

[in]  A kereséshez használt részkarakterlánc.

Visszatérési érték

A részkarakterlánc utolsó előfordulásának indexe (-1, ha a részkarakterlánc nem található).
