# Mid


Meghatározott hosszúságú részkarakterláncot kér le a megadott karakterlánc adott pozíciójától.

```cpp
string  Mid(
   uint  pos,       // position
   uint  count      // length
   )
```

Paraméterek

pos

[in] A részkarakterlánc kezdőpozíciója.

count

[in]  A részkarakterlánc hossza.

Visszatérési érték

A kapott részkarakterlánc.
