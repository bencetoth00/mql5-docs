# Copy

Referencia segítségével másol egy karakterláncot.

```cpp
void  Copy(
   string&  copy      // reference
   ) const;
```

Paraméterek

copy

[in]  Referencia egy adatokat tartalmazó karakterláncra.

Copy

Karakterláncot másol a CString osztálypéldányba.

```cpp
void  Copy(
   CString*  copy      // pointer
   ) const;
```

Paraméterek

copy

[in]  Pointer a CString osztály adatokat tároló példányára.
