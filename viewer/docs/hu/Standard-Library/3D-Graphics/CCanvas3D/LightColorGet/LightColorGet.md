# LightColorGet


Lekéri az irányított fényforrás színét és intenzitását.

```cpp
void  LightColorGet(
   DXColor  &light_color      // directional lighting color and intensity
   );
```

Paraméterek

&light\_color

[out]  Az irányított megvilágítás színe és intenzitása.

Visszatérési érték

Nincs.

Megjegyzés

Az intenzitás a DXColor struktúra alfa csatornájában van tárolva.
