# LightColorSet


Beállítja az irányított fényforrás színét és intenzitását.

```cpp
void  LightColorSet(
   const DXColor  &light_color      // directional lighting color and intensity
   );
```

Paraméterek

&light\_color

[in]  Az irányított megvilágítás színe és intenzitása.

Visszatérési érték

Nincs.

Megjegyzés

Az intenzitás a DXColor struktúra alfa csatornájában van beállítva.
