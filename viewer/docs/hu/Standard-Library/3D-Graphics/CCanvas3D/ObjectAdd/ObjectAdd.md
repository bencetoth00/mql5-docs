# ObjectAdd


Objektumot ad hozzá egy 3D-s jelenethez a későbbi rendereléshez.

```cpp
bool  ObjectAdd(
   CDXObject  *object      // pointer to the object
   );
```

Paraméterek

*object

[in]  Pointer a CDXObject absztrakt osztályból származó osztály példányára.

Visszatérési érték

true, ha sikerült hozzáadni a 3D-s grafikus objektumot, egyébként false.
