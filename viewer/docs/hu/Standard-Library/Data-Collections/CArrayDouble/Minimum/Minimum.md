# Minimum


Lekéri a tömb legkisebb elemének indexét a megadott tartományban.

```cpp
int  Minimum(
   int  start,     // starting index
   int  count      // number of elements
   ) const
```

Paraméterek

start

[in]  A keresési tartomány kezdőindexe.

count

[in]  A keresési tartomány mérete (elemek száma).

Visszatérési érték

A legkisebb elem indexe a megadott tartományban.
