# Maximum


Lekéri a tömb legnagyobb elemének indexét a megadott tartományban.

```cpp
int  Maximum(
   int  start,     // starting index
   int  count      // number of elements
   ) const
```

Paraméterek

start

[in]  A keresési tartomány kezdőindexe.

count

[in]  A keresési tartomány mérete (elemek száma).

Visszatérési érték

A legnagyobb elem indexe a megadott tartományban.
