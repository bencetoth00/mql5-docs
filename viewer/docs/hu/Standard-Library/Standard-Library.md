# Standard Library (standard könyvtár)

Ez a fejezet az MQL5 standard könyvtárának műszaki részleteit és fő összetevőinek leírását tartalmazza.

A standard könyvtár MQL5-ben készült. Célja, hogy megkönnyítse a felhasználói programok — indikátorok, szkriptek és Expert Advisorok — fejlesztését, és kényelmes hozzáférést biztosítson az MQL5 beépített funkcióinak többségéhez.

A könyvtár a terminál munkakönyvtárának `Include` mappájában található.
