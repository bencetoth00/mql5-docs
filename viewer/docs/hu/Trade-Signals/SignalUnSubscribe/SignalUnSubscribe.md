# SignalUnsubscribe


Megszünteti a feliratkozást.

```cpp
bool  SignalUnsubscribe();
```

Visszatérési érték

true értéket ad vissza, ha a feliratkozás megszüntetése sikeres volt, egyébként false értéket. A [hibáról](../../Constants,-Enumerations-and-Structures/Codes-of-Errors-and-Warnings/Runtime-Errors/Runtime-Errors.md) a [GetLastError()](../../Checkup/GetLastError/GetLastError.md) függvénnyel olvashat.
