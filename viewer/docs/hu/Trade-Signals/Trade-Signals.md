# Kereskedési jelzések

Ez a függvénycsoport a kereskedési jelzések kezelésére szolgál. A függvényekkel:

- lekérhetők a másolásra elérhető kereskedési jelzések adatai;
- lekérhetők és beállíthatók a jelzésmásolás paraméterei;
- MQL5-függvényekkel feliratkozhatsz a jelzésmásolásra, illetve lemondhatod az előfizetést.

| Függvény | Működés |
| --- | --- |
| [SignalBaseGetDouble](SignalBaseGetDouble/SignalBaseGetDouble.md) | Visszaadja a kiválasztott jelzés double típusú tulajdonságát. |
| [SignalBaseGetInteger](SignalBaseGetInteger/SignalBaseGetInteger.md) | Visszaadja a kiválasztott jelzés egész típusú tulajdonságát. |
| [SignalBaseGetString](SignalBaseGetString/SignalBaseGetString.md) | Visszaadja a kiválasztott jelzés szöveges tulajdonságát. |
| [SignalBaseSelect](SignalBaseSelect/SignalBaseSelect.md) | Kiválaszt egy, a terminálban elérhető jelzést további kezelésre. |
| [SignalBaseTotal](SignalBaseTotal/SignalBaseTotal.md) | Visszaadja a terminálban elérhető jelzések számát. |
| [SignalInfoGetDouble](SignalInfoGetDouble/SignalInfoGetDouble.md) | Visszaadja a jelzésmásolási beállítások double típusú tulajdonságát. |
| [SignalInfoGetInteger](SignalInfoGetInteger/SignalInfoGetInteger.md) | Visszaadja a jelzésmásolási beállítások egész típusú tulajdonságát. |
| [SignalInfoGetString](SignalInfoGetString/SignalInfoGetString.md) | Visszaadja a jelzésmásolási beállítások szöveges tulajdonságát. |
| [SignalInfoSetDouble](SignalInfoSetDouble/SignalInfoSetDouble.md) | Beállítja a jelzésmásolási beállítások double típusú tulajdonságát. |
| [SignalInfoSetInteger](SignalInfoSetInteger/SignalInfoSetInteger.md) | Beállítja a jelzésmásolási beállítások egész típusú tulajdonságát. |
| [SignalSubscribe](SignalSubscribe/SignalSubscribe.md) | Feliratkozik a kereskedési jelzésre. |
| [SignalUnsubscribe](SignalUnSubscribe/SignalUnSubscribe.md) | Lemond a kereskedési jelzésről. |
