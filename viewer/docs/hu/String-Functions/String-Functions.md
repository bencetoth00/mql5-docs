# Karakterlánc-függvények

Ez a függvénycsoport a [string](../Language-Basics/Data-Types/String-Type/String-Type.md) típusú adatok kezelésére szolgál.

| Függvény | Működés |
| --- | --- |
| [StringAdd](StringAdd/StringAdd.md) | Egy karakterláncot fűz egy másik végéhez. |
| [StringBufferLen](StringBufferLen/StringBufferLen.md) | Visszaadja a karakterlánchoz lefoglalt puffer méretét. |
| [StringCompare](StringCompare/StringCompare.md) | Összehasonlít két karakterláncot: 1-et ad vissza, ha az első nagyobb; 0-t, ha egyenlők; −1-et, ha az első kisebb. |
| [StringConcatenate](StringConcatenate/StringConcatenate.md) | Karakterláncot állít össze a megadott paraméterekből. |
| [StringFill](StringFill/StringFill.md) | A megadott karakterekkel tölti fel a karakterláncot. |
| [StringFind](StringFind/StringFind.md) | Részkarakterláncot keres egy karakterláncban. |
| [StringGetCharacter](StringGetCharacter/StringGetCharacter.md) | Visszaadja a megadott karakterláncpozíción található karakter kódját. |
| [StringInit](StringInit/StringInit.md) | A megadott karakterekkel és hosszal inicializál egy karakterláncot. |
| [StringLen](StringLen/StringLen.md) | Visszaadja a karakterlánc karaktereinek számát. |
| [StringSetLength](StringSetLength/StringSetLength.md) | Beállítja a karakterlánc hosszát karakterekben. |
| [StringReplace](StringReplace/StringReplace.md) | A megtalált részkarakterláncokat a megadott karakterekre cseréli. |
| [StringReserve](StringReserve/StringReserve.md) | Lefoglalja a megadott méretű memóriapuffert a karakterlánc számára. |
| [StringSetCharacter](StringSetCharacter/StringSetCharacter.md) | Visszaadja a karakterlánc másolatát, amelyben a megadott pozíció karaktere megváltozott. |
| [StringSplit](StringSplit/StringSplit.md) | A megadott elválasztó mentén részkarakterláncokra bontja a karakterláncot, és visszaadja a részek számát. |
| [StringSubstr](StringSubstr/StringSubstr.md) | A megadott pozíciótól kezdve kiemel egy részkarakterláncot. |
| [StringToLower](StringToLower/StringToLower.md) | A karakterlánc összes karakterét kisbetűssé alakítja. |
| [StringToUpper](StringToUpper/StringToUpper.md) | A karakterlánc összes karakterét nagybetűssé alakítja. |
| [StringTrimLeft](StringTrimLeft/StringTrimLeft.md) | Eltávolítja a sortöréseket, szóközöket és tabulátorokat a karakterlánc elejéről. |
| [StringTrimRight](StringTrimRight/StringTrimRight.md) | Eltávolítja a sortöréseket, szóközöket és tabulátorokat a karakterlánc végéről. |
