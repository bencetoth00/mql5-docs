# Eseményfüggvények

Ez a függvénycsoport az egyéni események és az időzítőesemények kezelésére szolgál. Az [előre definiált események](../Language-Basics/Functions/Event-Handling-Functions/Event-Handling-Functions.md) kezelésére külön függvények állnak rendelkezésre.

| Függvény | Működés |
| --- | --- |
| [EventSetMillisecondTimer](EventSetMillisecondTimer/EventSetMillisecondTimer.md) | Elindítja az aktuális diagram nagy felbontású időzítőjének eseménygenerátorát, amelynek periódusa 1 másodpercnél rövidebb. |
| [EventSetTimer](EventSetTimer/EventSetTimer.md) | Elindítja az aktuális diagram időzítőeseményeinek generátorát a megadott periódussal. |
| [EventKillTimer](EventKillTimer/EventKillTimer.md) | Leállítja az aktuális diagram időzítője által generált eseményeket. |
| [EventChartCustom](EventChartCustom/EventChartCustom.md) | Egyéni eseményt generál a megadott diagramhoz. |

Lásd még: [Diagram-események típusai](../Constants,-Enumerations-and-Structures/Chart-Constants/Types-of-Chart-Events/Types-of-Chart-Events.md).
