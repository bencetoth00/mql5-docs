# Kifejezések


Egy kifejezés egy vagy több operandusból és műveleti jelből áll. A kifejezés több sorba is tördelhető.

Példák:

```cpp
a++; b = 10;         // several expressions are located in one line
//---  one expression is divided into several lines
x = (y * z) /
    (w + 2) + 127;
```

A pontosvesszővel (;) végződő kifejezés utasítás.
