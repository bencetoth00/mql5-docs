# Állapotellenőrzés

# Állapotlekérdező függvények

Az ügyfélterminál aktuális állapotának paramétereit visszaadó függvények.

| Függvény | Működés |
| --- | --- |
| [GetLastError](GetLastError/GetLastError.md) | Visszaadja az utolsó hibát. |
| [IsStopped](IsStopped/IsStopped.md) | Igaz értéket ad vissza, ha az MQL5-program utasítást kapott a működés leállítására. |
| [UninitializeReason](UninitializeReason/UninitializeReason.md) | Visszaadja az inicializálás megszüntetésének okát jelző kódot. |
| [TerminalInfoInteger](TerminalInfoInteger/TerminalInfoInteger.md) | Visszaadja az MQL5-program környezetének megfelelő tulajdonságát egész számként. |
| [TerminalInfoDouble](TerminalInfoDouble/TerminalInfoDouble.md) | Visszaadja az MQL5-program környezetének megfelelő tulajdonságát double értékként. |
| [TerminalInfoString](TerminalInfoString/TerminalInfoString.md) | Visszaadja az MQL5-program környezetének megfelelő tulajdonságát szövegként. |
| [MQLInfoInteger](MQLInfoInteger/MQLInfoInteger.md) | Visszaadja a futó MQL5-program megfelelő tulajdonságát egész számként. |
| [MQLInfoString](MQLInfoString/MQLInfoString.md) | Visszaadja a futó MQL5-program megfelelő tulajdonságát szövegként. |
| [Symbol](Symbol/Symbol.md) | Visszaadja az aktuális diagram szimbólumának nevét. |
| [Period](Period/Period.md) | Visszaadja az aktuális diagram időkeretét. |
| [Digits](Digits/Digits.md) | Visszaadja az aktuális diagramszimbólum árának pontosságát meghatározó tizedesjegyek számát. |
| [Point](Point/Point.md) | Visszaadja az aktuális szimbólum pontértékét a jegyzési devizában. |
