# Számlaadatok

Az aktuális számla paramétereit visszaadó függvények.

| Függvény | Működés |
| --- | --- |
| [AccountInfoDouble](AccountInfoDouble/AccountInfoDouble.md) | A megfelelő számlatulajdonság double típusú értékét adja vissza. |
| [AccountInfoInteger](AccountInfoInteger/AccountInfoInteger.md) | A megfelelő számlatulajdonság egész típusú (bool, int vagy long) értékét adja vissza. |
| [AccountInfoString](AccountInfoString/AccountInfoString.md) | A megfelelő számlatulajdonság szöveges értékét adja vissza. |
