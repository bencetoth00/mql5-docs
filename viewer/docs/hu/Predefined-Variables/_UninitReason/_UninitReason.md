# _UninitReason

int \_UninitReason

Az \_UninitReason változó a program [inicializálásának megszüntetési okát](../../Constants,-Enumerations-and-Structures/Named-Constants/Uninitialization-Reason-Codes/Uninitialization-Reason-Codes.md) tartalmazó kódot tárolja.

Ezt a kódot rendszerint az [UninitializeReason()](../../Checkup/UninitializeReason/UninitializeReason.md) függvénnyel lehet lekérni.
