# _StopFlag

int \_StopFlag

Az \_StopFlag változó az MQL5-program leállítási jelzőjét tartalmazza. Normál működés közben az értéke 0. Amikor a kliens terminál le akarja állítani a programot, a változó értéke nem nulla lesz.

Az \_StopFlag állapotának ellenőrzéséhez az [IsStopped()](../../Checkup/IsStopped/IsStopped.md) függvény is használható.
