# Features

# Feature methods

These methods enable the receiving of matrix features, such as:

- number of rows
- number of columns
- norm
- condition number
- determinant
- matrix rank
- trace
- spectrum

| Function | Action |
| --- | --- |
| [Rows](Rows/Rows.md) | Return the number of rows in a matrix |
| [Cols](Cols/Cols.md) | Return the number of columns in a matrix |
| [Size](Size/Size.md) | Return the size of vector |
| [Norm](Norm/Norm.md) | Return matrix or vector norm |
| [Cond](Cond/Cond.md) | Compute the condition number of a matrix |
| [Det](Det/Det.md) | Compute the determinant of a square invertible matrix |
| [SLogDet](SLogDet/SLogDet.md) | Compute the sign and logarithm of the determinant of an matrix |
| [Rank](Rank/Rank.md) | Return matrix rank using the Gaussian method |
| [Trace](Trace/Trace.md) | Return the sum along diagonals of the matrix |
| [Spectrum](Spectrum/Spectrum.md) | Compute spectrum of a matrix as the set of its eigenvalues from the product AT\*A |
