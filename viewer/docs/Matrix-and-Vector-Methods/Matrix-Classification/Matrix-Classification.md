# Matrix Classification


The section describes a set of functions for analyzing the structural properties of matrices. These methods allow us to determine whether a matrix is symmetric, Hermitian, diagonal, triangular, trapezoidal, Hessenberg, bidiagonal, or scalar. Such a classification simplifies the selection of efficient algorithms for linear algebra and optimization of computations.

| Function | Action |
| --- | --- |
| [IsSymmetric](IsSymmetric/IsSymmetric.md) | Check if a square matrix is symmetric |
| [IsHermitian](IsHermitian/IsHermitian.md) | Check if a square complex matrix is Hermitian |
| [IsUpperTriangular](IsUpperTriangular/IsUpperTriangular.md) | Check if a square matrix is upper triangular |
| [IsLowerTriangular](IsLowerTriangular/IsLowerTriangular.md) | Check if a square matrix is lower triangular |
| [IsTrapezoidal](IsTrapezoidal/IsTrapezoidal.md) | Check if a rectangular (not square) m-by-n matrix is upper or lower trapezoidal |
| [IsUpperHessenberg](IsUpperHessenberg/IsUpperHessenberg.md) | Check if a square matrix is upper Hessenberg matrix |
| [IsLowerHessenberg](IsLowerHessenberg/IsLowerHessenberg.md) | Check if a square matrix is lower Hessenberg matrix |
| [IsTridiagonal](IsTridiagonal/IsTridiagonal.md) | Check if a square matrix is tridiagonal |
| [IsUpperBidiagonal](IsUpperBidiagonal/IsUpperBidiagonal.md) | Check if a square matrix is upper bidiagonal |
| [IsLowerBidiagonal](IsLowerBidiagonal/IsLowerBidiagonal.md) | Check if a square matrix is lower bidiagonal |
| [IsDiagonal](IsDiagonal/IsDiagonal.md) | Check if a square matrix is diagonal |
| [IsScalar](IsScalar/IsScalar.md) | Check if a square matrix is scalar matrix |
