# Compound Operator


A compound operator (a block) consists of one or more operators of any type, enclosed in braces {}. The closing brace must not be followed by a semicolon (;).

Example:

```cpp
if(x==0)
  {
   Print("invalid position x = ",x);
   return;
  }
```
