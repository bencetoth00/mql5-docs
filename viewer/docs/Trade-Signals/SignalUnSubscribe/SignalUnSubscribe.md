# SignalUnsubscribe


Cancels subscription.

```cpp
bool  SignalUnsubscribe();
```

Return Value

Returns true if subscription has been canceled successfully, otherwise returns false. To read more about the [error](../../Constants,-Enumerations-and-Structures/Codes-of-Errors-and-Warnings/Runtime-Errors/Runtime-Errors.md) call [GetLastError()](../../Checkup/GetLastError/GetLastError.md).
