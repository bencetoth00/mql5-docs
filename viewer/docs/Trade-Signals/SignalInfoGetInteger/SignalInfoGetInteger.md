# SignalInfoGetInteger


Returns the value of [integer](../../Language-Basics/Data-Types/Integer-Types/Integer-Types.md) type property of signal copy settings.

```cpp
long  SignalInfoGetInteger(
   ENUM_SIGNAL_INFO_INTEGER     property_id,     // property identifier
   );
```

Parameters

property\_id

[in]  Signal copy settings property identifier. The value can be one of the values of the [ENUM\_SIGNAL\_INFO\_INTEGER](../../Constants,-Enumerations-and-Structures/Trade-Constants/Signal-Properties/Signal-Properties.md#enum_signal_info_integer) enumeration.

Return Value

The value of [integer](../../Language-Basics/Data-Types/Integer-Types/Integer-Types.md) type property of signal copy settings.
