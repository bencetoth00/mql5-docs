# Jaw


Returns the buffer element of the Jaws line by the specified index.

```cpp
double  Jaw(
   int  index      // index
   )
```

Parameters

index

[in]  Jaws line buffer element index.

Return Value

The buffer element of the Jaws line by the specified index, or [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md) if there is no correct data.
