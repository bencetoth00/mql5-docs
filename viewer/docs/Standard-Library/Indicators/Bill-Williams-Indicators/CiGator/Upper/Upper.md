# Upper


Returns the element of the upper buffer by the specified index.

```cpp
double  Upper(
   int  index      // index
   )
```

Parameters

index

[in]  Upper buffer element index.

Return Value

The upper buffer element by the specified index, or [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md) if there is no correct data.
