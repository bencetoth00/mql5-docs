# PriceField


Returns the object (Low/High or Close/Close) to apply.

```cpp
ENUM_STO_PRICE  PriceField() const
```

Return Value

The object (Low/High or Close/Close) to apply, defined at the indicator creation ([ENUM\_STO\_PRICE](../../../../../Constants,-Enumerations-and-Structures/Indicator-Constants/Price-Constants/Price-Constants.md) enumeration value).
