# SenkouSpanB


Returns the buffer element of the SenkouSpanB line by the specified index.

```cpp
double  SenkouSpanB(
   int  index      // index
   )
```

Parameters

index

[in] SenkouSpanB line buffer element index.

Return Value

The buffer element of the SenkouSpanB line of the specified index, or [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md) if there is no correct data.
