# SenkouSpanA


Returns the buffer element of the SenkouSpanA line by the specified index.

```cpp
double  SenkouSpanA(
   int  index      // index
   )
```

Parameters

index

[in] SenkouSpanA line buffer element index.

Return Value

The buffer element of the SenkouSpanA line of the specified index, or [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md) if there is no correct data.
