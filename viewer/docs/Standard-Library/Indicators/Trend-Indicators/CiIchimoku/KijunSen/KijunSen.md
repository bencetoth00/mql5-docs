# KijunSen


Returns the buffer element of the KijunSen line by the specified index.

```cpp
double  KijunSen(
   int  index      // index
   )
```

Parameters

index

[in]  KijunSen line buffer element index.

Return Value

The buffer element of the KijunSen line of the specified index, or [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md) if there is no correct data.
