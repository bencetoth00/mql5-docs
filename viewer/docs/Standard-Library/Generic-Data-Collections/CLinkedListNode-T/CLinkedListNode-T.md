# CLinkedListNode<T>


CLinkedListNode<T> is a helper class used in implementing the CLinkedListNode<T> class.

### Description

The CLinkedListNode<T> class is a node of the doubly linked list CLinkedListNode<T>. List navigation methods are implemented in the class.

### Declaration

```cpp
   template<typename T>
   class CLinkedListNode
```

### Header

```cpp
   #include <Generic\LinkedList.mqh>
```

### Class Methods

| Method | Description |
| --- | --- |
| [List](List/List.md) | Returns and sets a pointer to the CLinkedList<T> |
| [Next](Next/Next.md) | Returns and sets a pointer to the next node |
| [Previous](Previous/Previous.md) | Returns and sets a pointer to the previous node |
| [Value](Value/Value.md) | Returns and sets the node value |
