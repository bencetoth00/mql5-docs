# EventObjectDelete


Sets a flag to send notifications of [events](../../../Constants,-Enumerations-and-Structures/Chart-Constants/Types-of-Chart-Events/Types-of-Chart-Events.md) of a graphical object deletion.

```cpp
bool  EventObjectDelete(
   bool  flag      // flag
   )
```

Parameters

flag

[in]  New value of a flag to send notifications of events of a graphical object deletion.

Return Value

true – successful, false - cannot change the flag.
