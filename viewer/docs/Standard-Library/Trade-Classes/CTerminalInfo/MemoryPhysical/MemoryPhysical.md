# MemoryPhysical


Gets the information about the physical memory (in Mb).

```cpp
int  MemoryPhysical() const
```

Return Value

Physical memory (in Mb).

Note

The physical memory is defined by [TerminalInfoInteger()](../../../../Checkup/TerminalInfoInteger/TerminalInfoInteger.md) function ([TERMINAL\_MEMORY\_PHYSICAL](../../../../Constants,-Enumerations-and-Structures/Environment-State/Client-Terminal-Properties/Client-Terminal-Properties.md#enum_terminal_info_integer) property).
