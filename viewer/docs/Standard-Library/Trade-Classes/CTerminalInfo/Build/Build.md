# Build


Gets the build number of the client terminal.

```cpp
int  CBuild() const
```

Return Value

Build number of the client terminal.

Note

The terminal build number is defined by [TerminalInfoInteger()](../../../../Checkup/TerminalInfoInteger/TerminalInfoInteger.md) function ([TERMINAL\_BUILD](../../../../Constants,-Enumerations-and-Structures/Environment-State/Client-Terminal-Properties/Client-Terminal-Properties.md#enum_terminal_info_integer) property).
