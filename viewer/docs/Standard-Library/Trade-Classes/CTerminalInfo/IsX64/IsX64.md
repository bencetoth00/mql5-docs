# IsX64


Gets the information about the type of the client terminal.

```cpp
bool  IsX64() const
```

Return Value

true - 64-bit version is used, otherwise - false.

Note

The type of the terminal is defined by [TerminalInfoInteger()](../../../../Checkup/TerminalInfoInteger/TerminalInfoInteger.md) function ([TERMINAL\_X64](../../../../Constants,-Enumerations-and-Structures/Environment-State/Client-Terminal-Properties/Client-Terminal-Properties.md#enum_terminal_info_integer) property).
