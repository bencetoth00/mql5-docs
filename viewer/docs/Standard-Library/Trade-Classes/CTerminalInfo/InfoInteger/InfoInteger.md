# InfoInteger


Returns the value of a corresponding integer property of the mql5 program environment.

```cpp
int  TerminalInfoInteger(
   int  property_id      // identifier of a property
   );
```

Parameters

property\_id

[in] Identifier of a property. It can be one of the values of the enumeration [ENUM\_TERMINAL\_INFO\_INTEGER](../../../../Constants,-Enumerations-and-Structures/Environment-State/Client-Terminal-Properties/Client-Terminal-Properties.md#enum_terminal_info_integer).

Return Value

Value of int type.

Note

The property value is defined by [TerminalInfoInteger()](../../../../Checkup/TerminalInfoInteger/TerminalInfoInteger.md) function.
