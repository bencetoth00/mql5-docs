# DataPath


Gets the information about the terminal data folder.

```cpp
string  DataPath() const
```

Return Value

Data folder of the client terminal.

Note

Client terminal data folder is defined by [TerminalInfoString()](../../../../Checkup/TerminalInfoString/TerminalInfoString.md) function ([TERMINAL\_DATA\_PATH](../../../../Constants,-Enumerations-and-Structures/Environment-State/Client-Terminal-Properties/Client-Terminal-Properties.md#enum_terminal_info_integer) property).
