# Name


Gets the information on the name of the client terminal.

```cpp
string  Name() const
```

Return Value

Name of the client terminal.

Note

The name of the terminal is defined by [TerminalInfoString()](../../../../Checkup/TerminalInfoString/TerminalInfoString.md) function ([TERMINAL\_NAME](../../../../Constants,-Enumerations-and-Structures/Environment-State/Client-Terminal-Properties/Client-Terminal-Properties.md#enum_terminal_info_integer) property).
