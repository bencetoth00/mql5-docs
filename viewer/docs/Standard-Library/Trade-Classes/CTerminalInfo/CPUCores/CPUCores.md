# CPUCores


Gets the information about the number of CPU cores in the system.

```cpp
int  CPUCores() const
```

Return Value

Number of CPU cores in the system.

Note

The number of CPU cores is defined by [TerminalInfoInteger()](../../../../Checkup/TerminalInfoInteger/TerminalInfoInteger.md) function ([TERMINAL\_CPU\_CORES](../../../../Constants,-Enumerations-and-Structures/Environment-State/Client-Terminal-Properties/Client-Terminal-Properties.md#enum_terminal_info_integer) property).
