# IsTradeAllowed


Gets the information about permission to trade.

```cpp
bool  IsTradeAllowed() const
```

Return Value

true - trade allowed, otherwise - false.

Note

Permission to trade is defined by [TerminalInfoInteger()](../../../../Checkup/TerminalInfoInteger/TerminalInfoInteger.md) function ([TERMINAL\_TRADE\_ALLOWED](../../../../Constants,-Enumerations-and-Structures/Environment-State/Client-Terminal-Properties/Client-Terminal-Properties.md#enum_terminal_info_integer) property).
