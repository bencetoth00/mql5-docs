# TradeExecution


Gets the trade execution mode.

```cpp

```

Return Value

Trade execution mode from [ENUM\_SYMBOL\_TRADE\_EXECUTION](../../../../Constants,-Enumerations-and-Structures/Environment-State/Symbol-Properties/Symbol-Properties.md#enum_symbol_trade_execution) enumeration.
