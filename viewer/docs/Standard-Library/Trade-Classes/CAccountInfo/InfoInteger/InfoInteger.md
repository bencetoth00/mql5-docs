# InfoInteger


Gets the value of specified integer type property.

```cpp
long  InfoInteger(
   ENUM_ACCOUNT_INFO_INTEGER  prop_id     // property ID
   ) const
```

Parameters

prop\_id

[in]  Identifier of the property. The value can be one of the values of [ENUM\_ACCOUNT\_INFO\_INTEGER](../../../../Constants,-Enumerations-and-Structures/Environment-State/Account-Properties/Account-Properties.md#enum_account_info_integer) enumeration.

Return Value

Value of [long](../../../../Language-Basics/Data-Types/Integer-Types/Char,-Short,-Int-and-Long-Types/Char,-Short,-Int-and-Long-Types.md) type.
