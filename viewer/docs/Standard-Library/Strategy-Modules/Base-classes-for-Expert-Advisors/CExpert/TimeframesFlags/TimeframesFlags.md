# TimeframesFlags


Forms the timeframe flags.

```cpp
int  TimeframesFlags(
   MqlDateTime&    time         // reference
   )
```

Parameters

time

[in]  Reference to [MqlDateTime](../../../../../Constants,-Enumerations-and-Structures/Data-Structures/Date-Type-Structure/Date-Type-Structure.md) type structure containing a new time.

Return Value

It returns the flag that indicates timeframes with a new bar.
