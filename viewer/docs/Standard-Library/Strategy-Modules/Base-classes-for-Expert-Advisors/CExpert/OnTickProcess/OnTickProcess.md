# OnTickProcess


Sets the [OnTick](../../../../../Event-Handling/OnTick/OnTick.md) event handling flag.

```cpp
void  OnTickOProcess(
   bool     value        // flag
   )
```

Parameters

value

[in] [OnTick](../../../../../Event-Handling/OnTick/OnTick.md) event handling flag.

Return Value

None.

Note

If the flag is true, the [OnTick](../../../../../Event-Handling/OnTick/OnTick.md) event is handled. By default, the flag is set to true.
