# OnTimerProcess


Sets the [OnTimer](../../../../../Event-Handling/OnTimer/OnTimer.md) event handling flag.

```cpp
void  OnTimerProcess(
   bool     value        // flag
   )
```

Parameters

value

[in] [OnTimer](../../../../../Event-Handling/OnTimer/OnTimer.md) event handling flag.

Return Value

None.

Note

If the flag is true, the [OnTimer](../../../../../Event-Handling/OnTimer/OnTimer.md) event is handled. By default, the flag is set to false.
