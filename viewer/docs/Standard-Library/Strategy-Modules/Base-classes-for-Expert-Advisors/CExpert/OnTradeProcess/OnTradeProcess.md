# OnTradeProcess


Sets the [OnTrade](../../../../../Event-Handling/OnTrade/OnTrade.md) event handling flag.

```cpp
void  OnTradeProcess(
   bool     value        // flag
   )
```

Parameters

value

[in] [OnTrade](../../../../../Event-Handling/OnTrade/OnTrade.md) event handling flag.

Return Value

None.

Note

If the flag is true, the [OnTrade](../../../../../Event-Handling/OnTrade/OnTrade.md) event is handled. By default, the flag is set to false.
