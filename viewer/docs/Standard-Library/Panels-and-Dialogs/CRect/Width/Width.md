# Width

# Width (Get Method)

Gets the width of the area.

```cpp
int  Width()
```

Return Value

Width of the area.

 

# Width (Set Method)

Sets new width of the area.

```cpp
virtual bool  Width(
   const int  w      // width
   )
```

Parameters

w

[in]  New width.

Return Value

true - successful, otherwise - false.
