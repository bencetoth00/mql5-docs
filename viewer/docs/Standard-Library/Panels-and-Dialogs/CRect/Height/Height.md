# Height

# Height (Get Method)

Gets the height of the area.

```cpp
int  Height()
```

Return Value

Height of the area.

 

# Height (Set Method)

Sets new height of the area.

```cpp
virtual bool  Height(
   const int  h      // height
   )
```

Parameters

h

[in]  New height.

Return Value

true - successful, otherwise - false.
