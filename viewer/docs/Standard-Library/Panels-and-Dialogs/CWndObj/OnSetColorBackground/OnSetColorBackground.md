# OnSetColorBackground


The virtual handler of control "SetColorBackground" (change of the [OBJPROP\_BGCOLOR](../../../../Constants,-Enumerations-and-Structures/Objects-Constants/Object-Properties/Object-Properties.md#enum_object_property_integer) property) event.

```cpp
virtual bool  OnSetColorBackground()
```

Return Value

true - event processed, otherwise - false.

Note

The base class method does nothing and always returns true.
