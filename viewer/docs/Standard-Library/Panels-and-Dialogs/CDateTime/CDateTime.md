# CDateTime


CDateTime is a structure for working with date and time.

### Description

CDateTime is a structure derived from [MqlDateTime](../../../Constants,-Enumerations-and-Structures/Data-Structures/Date-Type-Structure/Date-Type-Structure.md), it used for operation with date and time in controls.

### Declaration

```cpp
   struct CDateTime
```

### Title

