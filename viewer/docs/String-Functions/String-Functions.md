# String Functions


This is a group of functions intended for working with data of the [string](../Language-Basics/Data-Types/String-Type/String-Type.md) type.

| Function | Action |
| --- | --- |
| [StringAdd](StringAdd/StringAdd.md) | Adds a string to the end of another string |
| [StringBufferLen](StringBufferLen/StringBufferLen.md) | Returns the size of buffer allocated for the string |
| [StringCompare](StringCompare/StringCompare.md) | Compares two strings and returns 1 if the first string is greater than the second; 0 - if the strings are equal; -1 (minus 1) - if the first string is less than the second one |
| [StringConcatenate](StringConcatenate/StringConcatenate.md) | Forms a string of parameters passed |
| [StringFill](StringFill/StringFill.md) | Fills out a specified string by selected symbols |
| [StringFind](StringFind/StringFind.md) | Search for a substring in a string |
| [StringGetCharacter](StringGetCharacter/StringGetCharacter.md) | Returns the value of a number located in the specified string position |
| [StringInit](StringInit/StringInit.md) | Initializes string by specified symbols and provides the specified string length |
| [StringLen](StringLen/StringLen.md) | Returns the number of symbols in a string |
| [StringSetLength](StringSetLength/StringSetLength.md) | Sets a specified length (in characters) for a string |
| [StringReplace](StringReplace/StringReplace.md) | Replaces all the found substrings of a string by a set sequence of symbols |
| [StringReserve](StringReserve/StringReserve.md) | Reserves the buffer of a specified size for a string in memory. |
| [StringSetCharacter](StringSetCharacter/StringSetCharacter.md) | Returns a copy of a string with a changed value of a symbol in a specified position |
| [StringSplit](StringSplit/StringSplit.md) | Gets substrings by a specified separator from the specified string, returns the number of substrings obtained |
| [StringSubstr](StringSubstr/StringSubstr.md) | Extracts a substring from a text string starting from a specified position |
| [StringToLower](StringToLower/StringToLower.md) | Transforms all symbols of a selected string to lowercase |
| [StringToUpper](StringToUpper/StringToUpper.md) | Transforms all symbols of a selected string into capitals |
| [StringTrimLeft](StringTrimLeft/StringTrimLeft.md) | Cuts line feed characters, spaces and tabs in the left part of the string |
| [StringTrimRight](StringTrimRight/StringTrimRight.md) | Cuts line feed characters, spaces and tabs in the right part of the string |
