# Trade Signals

Trade Signals

This is the group of functions intended for managing trade signals. The functions allow:

- get information about trade signals, available for copying,
- get and set the signal copy settings,
- subscribe and unsubscribe to the signal copying using MQL5 language functions.

| Function | Action |
| --- | --- |
| [SignalBaseGetDouble](SignalBaseGetDouble/SignalBaseGetDouble.md) | Returns the value of double type property for selected signal |
| [SignalBaseGetInteger](SignalBaseGetInteger/SignalBaseGetInteger.md) | Returns the value of integer type property for selected signal |
| [SignalBaseGetString](SignalBaseGetString/SignalBaseGetString.md) | Returns the value of string type property for selected signal |
| [SignalBaseSelect](SignalBaseSelect/SignalBaseSelect.md) | Selects a signal from signals, available in terminal for further working with it |
| [SignalBaseTotal](SignalBaseTotal/SignalBaseTotal.md) | Returns the total amount of signals, available in terminal |
| [SignalInfoGetDouble](SignalInfoGetDouble/SignalInfoGetDouble.md) | Returns the value of double type property of signal copy settings |
| [SignalInfoGetInteger](SignalInfoGetInteger/SignalInfoGetInteger.md) | Returns the value of integer type property of signal copy settings |
| [SignalInfoGetString](SignalInfoGetString/SignalInfoGetString.md) | Returns the value of string type property of signal copy settings |
| [SignalInfoSetDouble](SignalInfoSetDouble/SignalInfoSetDouble.md) | Sets the value of double type property of signal copy settings |
| [SignalInfoSetInteger](SignalInfoSetInteger/SignalInfoSetInteger.md) | Sets the value of integer type property of signal copy settings |
| [SignalSubscribe](SignalSubscribe/SignalSubscribe.md) | Subscribes to the trading signal |
| [SignalUnsubscribe](SignalUnSubscribe/SignalUnSubscribe.md) | Cancels subscription |
