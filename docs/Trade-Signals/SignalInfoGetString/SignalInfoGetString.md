# SignalInfoGetString

SignalInfoGetString

Returns the value of [string](../../Language-Basics/Data-Types/String-Type/String-Type.md) type property of signal copy settings.

|  |
| --- |
| string  SignalInfoGetString(     ENUM\_SIGNAL\_INFO\_STRING     property\_id,     // property identifier     ); |

Parameters

property\_id

[in]  Signal copy settings property identifier. The value can be one of the values of the [ENUM\_SIGNAL\_INFO\_STRING](../../Constants,-Enumerations-and-Structures/Trade-Constants/Signal-Properties/Signal-Properties.md#enum_signal_info_string) enumeration.

Return Value

The value of [string](../../Language-Basics/Data-Types/String-Type/String-Type.md) type property of signal copy settings.
