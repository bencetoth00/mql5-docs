# Upper

Upper

Returns the buffer element of the upper line by the specified index.

|  |
| --- |
| double  Upper(     int  index      // index     ) |

Parameters

index

[in]  Upper line buffer element index.

Return Value

The buffer element of the upper line of the specified index, or [EMPTY\_VALUE](../../../../../Constants,-Enumerations-and-Structures/Named-Constants/Other-Constants/Other-Constants.md) if there is no correct data.
