# Timeseries classes

Timeseries classes

This group of chapters contains technical details of timeseries classes of the MQL5 Standard Library and descriptions of all its key components.

| Class | Description |
| --- | --- |
| [CiSpread](CiSpread/CiSpread.md) | Provides an access to spread historical data |
| [CiTime](CiTime/CiTime.md) | Provides an access to open times of the bars in the history |
| [CiTickVolume](CiTickVolume/CiTickVolume.md) | Provides an access to tick volumes of the bars in the history |
| [CiRealVolume](CiRealVolume/CiRealVolume.md) | Provides an access to real volumes of the bars in the history |
| [CiOpen](CiOpen/CiOpen.md) | Provides an access to open prices of the bars in the history |
| [CiHigh](CiHigh/CiHigh.md) | Provides an access to high prices of the bars in the history |
| [CiLow](CiLow/CiLow.md) | Provides an access to low prices of the bars in the history |
| [CiClose](CiClose/CiClose.md) | Provides an access to close prices of the bars in the history |
