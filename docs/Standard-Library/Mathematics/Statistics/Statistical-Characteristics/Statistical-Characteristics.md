# Statistical Characteristics

Statistical Characteristics

This group of functions calculates the Statistical Characteristics of the array elements:

- mean,
- variance,
- skewness,
- kurtosis,
- median,
- root-mean-square and
- standard deviation.

| Function | Description |
| --- | --- |
| [MathMean](MathMean/MathMean.md) | Calculates the mean (first moment) of array elements |
| [MathVariance](MathVariance/MathVariance.md) | Calculates the variance (second moment) of array elements |
| [MathSkewness](MathSkewness/MathSkewness.md) | Calculates the skewness (third moment) of array elements |
| [MathKurtosis](MathKurtosis/MathKurtosis.md) | Calculates the kurtosis (fourth moment) of array elements |
| [MathMoments](MathMoments/MathMoments.md) | Calculates the first 4 moments (mean, variance, skewness, kurtosis) of array elements |
| [MathMedian](MathMedian/MathMedian.md) | Calculates the median value of array elements |
| [MathStandardDeviation](MathStandardDeviation/MathStandardDeviation.md) | Calculates the standard deviation of array elements |
| [MathAverageDeviation](MathAverageDeviation/MathAverageDeviation.md) | Calculates the average absolute deviation of array elements |
