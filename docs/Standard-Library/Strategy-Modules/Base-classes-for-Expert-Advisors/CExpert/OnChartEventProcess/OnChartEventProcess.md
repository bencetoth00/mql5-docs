# OnChartEventProcess

OnChartEventProcess

Sets a flag to handle the [OnChartEvent](../../../../../Event-Handling/OnChartEvent/OnChartEvent.md) event.

|  |
| --- |
| void  OnChartEventProcess(     bool     value        // flag     ) |

Parameters

value

[in] Flag to handle the [OnChartEvent](../../../../../Event-Handling/OnChartEvent/OnChartEvent.md) event.

Return Value

None.

Note

If the flag is true, the [OnChartEvent](../../../../../Event-Handling/OnChartEvent/OnChartEvent.md) event is handled. By default, the flag is set to false.
