# MemoryAvailable

MemoryAvailable

Gets the information about the free memory available to the client terminal/agent (in Mb).

|  |
| --- |
| int  MemoryTotal() const |

Return Value

Free memory (in Mb) available to the terminal/agent.

Note

The free memory available to the client terminal/agent is defined by [TerminalInfoInteger()](../../../../Checkup/TerminalInfoInteger/TerminalInfoInteger.md) function ([TERMINAL\_MEMORY\_TOTAL](../../../../Constants,-Enumerations-and-Structures/Environment-State/Client-Terminal-Properties/Client-Terminal-Properties.md#enum_terminal_info_integer) property).
