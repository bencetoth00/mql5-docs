# TimeMsc

TimeMsc

Receives position opening time in milliseconds since 01.01.1970.

|  |
| --- |
| ulong  TimeMsc() const |

Return Value

Position opening time in milliseconds since 01.01.1970.

Note

Position should be preliminarily selected for access using [Select](../Select/Select.md) (by symbol) or [SelectByIndex](../SelectByIndex/SelectByIndex.md) (by index) method.
