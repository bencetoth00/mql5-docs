# Account Information

Account Information

Functions that return parameters of the current account.

| Function | Action |
| --- | --- |
| [AccountInfoDouble](AccountInfoDouble/AccountInfoDouble.md) | Returns a value of double type of the corresponding account property |
| [AccountInfoInteger](AccountInfoInteger/AccountInfoInteger.md) | Returns a value of integer type (bool, int or long) of the corresponding account property |
| [AccountInfoString](AccountInfoString/AccountInfoString.md) | Returns a value string type corresponding account property |
