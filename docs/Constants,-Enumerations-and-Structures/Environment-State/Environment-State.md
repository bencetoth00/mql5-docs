# Environment State

Environment State

Constants describing the current runtime environment of an mql5-program are divided into groups:

- [Client terminal properties](Client-Terminal-Properties/Client-Terminal-Properties.md) – information about the client terminal;
- [Executed MQL5-program properties](Running-MQL5-Program-Properties/Running-MQL5-Program-Properties.md) –  mql5 program properties, which help to control its execution;
- [Symbol properties](Symbol-Properties/Symbol-Properties.md) – obtaining information about a symbol;
- [Account properties](Account-Properties/Account-Properties.md)  – information about the current account;

- [Testing Statistics](Testing-Statistics/Testing-Statistics.md) – results of Expert Advisor testing.
