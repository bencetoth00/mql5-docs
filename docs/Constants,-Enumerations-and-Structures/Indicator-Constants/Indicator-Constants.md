# Indicator Constants

Indicators Constants

There are 37 predefined [technical indicators](../../Technical-Indicators/Technical-Indicators.md), which can be used in programs written in the MQL5 language. In addition, there is an opportunity to create custom indicators using the [iCustom()](../../Technical-Indicators/iCustom/iCustom.md) function. All constants required for that are divided into 5 groups:

- [Price constants](Price-Constants/Price-Constants.md) – for selecting the type of price or volume, on which an indicator is calculated;
- [Smoothing methods](Smoothing-Methods/Smoothing-Methods.md) – built-in smoothing methods used in indicators;
- [Indicator lines](Indicators-Lines/Indicators-Lines.md) – identifiers of indicator buffers when accessing indicator values using [CopyBuffer()](../../Timeseries-and-Indicators-Access/CopyBuffer/CopyBuffer.md);
- [Drawing styles](Drawing-Styles/Drawing-Styles.md) – for indicating one of 18 types of drawing and setting the line drawing style;
- [Custom indicators properties](Custom-Indicator-Properties/Custom-Indicator-Properties.md) are used in functions for working with [custom](../../Custom-Indicators/Custom-Indicators.md) indicators;
- [Types of indicators](Indicator-Types/Indicator-Types.md) are used for specifying the type of technical indicator when creating a handle using [IndicatorCreate()](../../Timeseries-and-Indicators-Access/IndicatorCreate/IndicatorCreate.md);
- [Identifiers of data types](Data-Type-Identifiers/Data-Type-Identifiers.md) are used for specifying the type of data passed in an array of the [MqlParam](../Data-Structures/Indicator-Parameter-Structure/Indicator-Parameter-Structure.md) type into the [IndicatorCreate()](../../Timeseries-and-Indicators-Access/IndicatorCreate/IndicatorCreate.md) function.
