# Objects Constants

Object Constants

There are 44 graphical objects that can be created and displayed in the price chart. All constants for working with objects are divided into 9 groups:

- [Object types](Object-Types/Object-Types.md) – Identifiers of graphical objects;
- [Object properties](Object-Properties/Object-Properties.md) – setting and getting properties of graphical objects;
- [Methods of object binding](Methods-of-Object-Binding/Methods-of-Object-Binding.md) – constants of object positioning in the chart;
- [Binding corner](Chart-Corner/Chart-Corner.md) – setting the corner relative to which an object is positioned on chart;
- [Visibility of objects](Visibility-of-Objects/Visibility-of-Objects.md) – setting timeframes in which an object is visible;
- [Levels of Elliott Waves](Levels-of-Elliott-Wave/Levels-of-Elliott-Wave.md) – gradation of waves;
- [Gann objects](Gann-Objects/Gann-Objects.md) – trend constants for Gann fan and Gann grid;
- [Web colors](Web-Colors/Web-Colors.md) – constants of predefined web colors;
- [Wingdings](Wingdings/Wingdings.md) – codes of characters of the Wingdings font.
