# OBJ_ARROW

OBJ\_ARROW

Arrow object.

![ObjArrow](../../../../assets/objarrow.png)

Note

Anchor point position relative to the object can be selected from [ENUM\_ARROW\_ANCHOR](../../Methods-of-Object-Binding/Methods-of-Object-Binding.md#enum_arrow_anchor).

Large arrows (more than 5) can only be created by setting the appropriate [OBJPROP\_WIDTH](../../Object-Properties/Object-Properties.md#enum_object_property_integer) property value when writing a code in MetaEditor.

The necessary arrow type can be selected by setting one of the [Wingdings](../../Wingdings/Wingdings.md) font's symbol codes.

Example

The following script creates Arrow object on the chart and changes its type. Special functions have been developed to create and change graphical object's properties. You can use these functions "as is" in your own applications.
