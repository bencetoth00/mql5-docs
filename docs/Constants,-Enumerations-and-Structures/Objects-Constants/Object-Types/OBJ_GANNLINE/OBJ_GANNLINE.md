# OBJ_GANNLINE

OBJ\_GANNLINE

Gann Line.

![ObjGannLine](../../../../assets/objgannline.png)

Note

For Gann Line, it is possible to specify the mode of continuation of its display to the right and/or left ([OBJPROP\_RAY\_RIGHT](../../Object-Properties/Object-Properties.md#enum_object_property_integer) and [OBJPROP\_RAY\_LEFT](../../Object-Properties/Object-Properties.md#enum_object_property_integer) properties accordingly).

Both Gann angle with a scale and coordinates of the second anchor point can be used to set the slope of the line.

Example

The following script creates and moves Gann Line on the chart. Special functions have been developed to create and change graphical object's properties. You can use these functions "as is" in your own applications.

//+------------------------------------------------------------------+  //| Move Gann Line anchor point                                      |  //+------------------------------------------------------------------+  bool GannLinePointChange(const long   chart\_ID=0,      // chart's ID //+------------------------------------------------------------------+  //| Check the values of Gann Line anchor points and set default      | void ChangeGannLineEmptyPoints(datetime &time1,double &price1,datetime &time2)    {  //--- if the second point's time is not set, it will be on the current bar     if(!time2)
