# OBJ_STDDEVCHANNEL

OBJ\_STDDEVCHANNEL

Standard Deviation Channel.

![ObjStdDevChannel](../../../../assets/objstddevchannel.png)

Note

For Standard Deviation Channel, it is possible to specify the mode of continuation of its display to the right and/or left ([OBJPROP\_RAY\_RIGHT](../../Object-Properties/Object-Properties.md#enum_object_property_integer) and [OBJPROP\_RAY\_LEFT](../../Object-Properties/Object-Properties.md#enum_object_property_integer) properties accordingly). The mode of filling the channel with color can also be set.

[OBJPROP\_DEVIATION](../../Object-Properties/Object-Properties.md#enum_object_property_double) property is used to change the value of the channel deviation.

Example

The following script creates and moves Standard Deviation Channel on the chart. Special functions have been developed to create and change graphical object's properties. You can use these functions "as is" in your own applications.

   ObjectSetInteger(chart\_ID,name,OBJPROP\_BACK,back);  //--- enable (true) or disable (false) the mode of highlighting the channel for moving  //--- successful execution     return(true);    }  //+------------------------------------------------------------------+  //| Move the channel's anchor point                                  |
