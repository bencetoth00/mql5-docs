# Statistics

Statistical methods

Methods for computing descriptive statistics of matrices and vectors.

| Function | Action |
| --- | --- |
| [ArgMax](ArgMax/ArgMax.md) | Return the index of the maximum value |
| [ArgMin](ArgMin/ArgMin.md) | Return the index of the minimum value |
| [Max](Max/Max.md) | Return the maximum value in a matrix/vector |
| [Min](Min/Min.md) | Return the minimum value in a matrix/vector |
| [Ptp](Ptp/Ptp.md) | Return the range of values of a matrix/vector or of the given matrix axis |
| [Sum](Sum/Sum.md) | Return the sum of the matrix/vector elements which can also be performed for the given axis (axes) |
| [Prod](Prod/Prod.md) | Return the product of the matrix/vector elements which can also be performed for the given axis |
| [CumSum](CumSum/CumSum.md) | Return the cumulative sum of matrix/vector elements, including those along the given axis |
| [CumProd](CumProd/CumProd.md) | Return the cumulative product of matrix/vector elements, including those along the given axis |
| [Percentile](Percentile/Percentile.md) | Return the specified percentile of values of matrix/vector elements or elements along the specified axis |
| [Quantile](Quantile/Quantile.md) | Return the specified quantile of values of matrix/vector elements or elements along the specified axis |
| [Median](Median/Median.md) | Compute the median of the matrix/vector elements |
| [Mean](Mean/Mean.md) | Compute the arithmetic mean of element values |
| [Average](Average/Average.md) | Compute the weighted mean of matrix/vector values |
| [Std](Std/Std.md) | Return the standard deviation of values of matrix/vector elements or of elements along the given axis |
| [Var](Var/Var.md) | Compute the variance of values of matrix/vector elements |
| [LinearRegression](LinearRegression/LinearRegression.md) | Calculate a vector/matrix with calculated linear regression values |
