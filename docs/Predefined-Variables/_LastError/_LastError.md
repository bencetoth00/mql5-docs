# _LastError

int \_LastError

The \_LastError variable contains code of the last [error](../../Constants,-Enumerations-and-Structures/Codes-of-Errors-and-Warnings/Runtime-Errors/Runtime-Errors.md), that occurred during the mql5-program run. Its value can be reset to zero by [ResetLastError()](../../Common-Functions/ResetLastError/ResetLastError.md).

To obtain the code of the last error,  you may also use the [GetLastError()](../../Checkup/GetLastError/GetLastError.md) function.
