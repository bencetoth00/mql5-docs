# StringFormat

StringFormat

The function formats obtained parameters and returns a string.

|  |
| --- |
| string  StringFormat(     string  format,     // string with format description     ...     ...         // parameters     ); |

Parameters

format

[in]  String containing method of formatting. Formatting rules are the same as for the [PrintFormat](../../Common-Functions/PrintFormat/PrintFormat.md) function.

...

[in]  Parameters, separated by a comma.

Return Value

String.

      }  //--- string value output     temp\_string=StringFormat("   SYMBOL\_TRADE\_CALC\_MODE = %s\n",                              str\_calc\_mode);     StringAdd(output\_string,temp\_string);  //--- double value output with 2 digits after the decimal point     double margin\_initial=SymbolInfoDouble(\_Symbol,SYMBOL\_MARGIN\_INITIAL);
