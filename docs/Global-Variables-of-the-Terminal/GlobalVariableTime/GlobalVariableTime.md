# GlobalVariableTime

GlobalVariableTime

Returns the time when the global variable was last accessed.

|  |
| --- |
| datetime  GlobalVariableTime(     string  name      // name     ); |

Parameters

name

[in]  Name of the global variable.

Return Value

The function returns time of last accessing the specified global variable. Addressing a variable for its value, for example using the [GlobalVariableGet()](../GlobalVariableGet/GlobalVariableGet.md) and [GlobalVariableCheck()](../GlobalVariableCheck/GlobalVariableCheck.md) functions, also modifies the time of last access. In order to obtain [error](../../Constants,-Enumerations-and-Structures/Codes-of-Errors-and-Warnings/Runtime-Errors/Runtime-Errors.md) details, call the [GetLastError()](../../Checkup/GetLastError/GetLastError.md) function.

Note

Global variables exist in the client terminal during 4 weeks since they were called last. After that they are automatically deleted.
